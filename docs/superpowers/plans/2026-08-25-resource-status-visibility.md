# 资源同步状态可见性实施计划

**目标：** 将资源同步状态移到设置页标题行右侧，使用独立醒目的状态样式，并避免同一次结果轮询吞掉后台持续追加的全部进度事件。

**架构：** 设置对话框负责标题行布局和状态文案；应用层仍通过现有结果队列更新状态，但每次轮询只处理调用开始时已经排队的事件快照。无更新和下载成功统一进入“资源已是最新”完成状态，不增加人为展示延时。
