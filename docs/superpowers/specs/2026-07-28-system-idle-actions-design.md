# 系统空闲动作设计

## 目标

基于 Windows 全系统最后输入时间而非宠物窗口事件，让宠物在无人操作时进入无聊或睡眠状态，并在恢复输入时播放唤醒动作。

## 规则

- 每秒读取一次平台适配器的空闲秒数，不读取或保存输入内容。
- 小于无聊阈值：活动状态；从无聊/睡眠恢复时发布一次 `system.wake`。
- 达到无聊阈值（默认 30 秒）：发布一次 `system.bored`。
- 达到睡眠阈值（默认 180 秒）：发布一次 `system.sleep`。
- 同一状态不重复发布；阈值必须满足睡眠秒数大于无聊秒数。

## 宠物包与兼容性

`system.bored`、`system.sleep` 与 `system.wake` 是标准事件。包可将它们绑定到 `bored`、`sleep`、`wake` 动作；动作或资源不存在时回退到 `idle`。新导入的精灵图包写入这些绑定。已有包也在运行时获得同一套安全默认绑定，包内显式绑定优先。

## 设置

设置页提供启用开关、无聊秒数和睡眠秒数。默认关闭。Windows 以外平台无法取得空闲时间时静默不触发，不影响其他动作。
