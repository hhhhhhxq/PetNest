# 下班全屏动画与加班提醒设计

## 目标

当当天实际下班倒计时结束时，在桌宠所在屏幕播放一次透明置顶的全屏宠物动画：宠物从屏幕右侧走到中央，随后躺下并停留。屏幕左上角同时提供“下班”和“再加一会”两个操作。提醒在 30 分钟内无人处理时自动按“下班”处理。

用户选择继续加班后，原倒计时卡片显示累计加班时长，并在每满一小时后再次播放同一提醒。功能支持固定排班与弹性打卡，能在应用重启、系统休眠和换宠物后保持正确行为。

## 已确认的产品行为

### 首次下班提醒

- 触发基准是当天实际下班时刻：固定模式使用当天排班时间，弹性模式使用打卡时间与工作时长计算出的下班时间。
- 到达下班时刻时只触发一次全屏提醒。
- 如果应用当天首次启动时已经超过下班时刻，且当天还没有作出选择，则立即补播一次提醒。
- 动画和操作面板显示在桌宠当前所在屏幕；桌宠之后换屏时，下一次提醒使用新的所在屏幕。
- 动画层透明、置顶且鼠标穿透，不遮挡桌面操作。左上角操作面板是独立的可交互置顶窗口。

### 动画行为

- 宠物从目标屏幕右侧完全出屏的位置进入。
- 走入阶段约 4 秒，到达屏幕中央后播放约 2 秒的躺下过渡。
- 最后一帧保持不动，直到用户选择或 30 分钟超时。
- 动画保持素材原始宽高比，不拉伸变形。
- 帧画布显示宽度约为目标屏幕宽度的 92%，使宠物覆盖绝大部分屏幕。
- 所有帧使用一致的缩放比例和地面锚点，避免动作过程中发生尺寸跳变。

### 操作与加班计时

- 动画开始时，左上角同时出现“下班”和“再加一会”按钮，并显示自动关闭剩余时间。
- 点击“下班”后立即关闭两个提醒窗口，倒计时卡片继续显示“下班啦 🎉”，当天不再提醒。
- 点击“再加一会”后立即关闭两个提醒窗口，恢复桌面操作。
- 加班时长从原定实际下班时刻开始累计，而不是从点击按钮的时刻开始。
- 加班期间倒计时卡片显示“你已加班 HH:MM:SS”。
- 在原定实际下班时刻后的每个整小时节点重新播放全屏提醒。例如实际下班时刻为 18:40，则后续节点为 19:40、20:40、21:40。
- 每次小时提醒仍提供相同的两个按钮。选择“再加一会”继续原累计时长，不清零。
- 任意一次提醒连续 30 分钟无人选择时，自动按“下班”处理。
- 应用错过小时提醒节点时，在恢复运行后立即补播一次，不连续补播多个历史节点；处理后从下一个未来小时节点继续。

## 宠物动画资源与回退

### 全屏作用域动画

专属全屏动画直接放入当前宠物的普通 `animations/`，使用两个动作名区分阶段：

```text
pets/<pet-id>/animations/
├─ work_finish_walk/
└─ work_finish_lie_down/
```

本次用户提供的橘猫素材属于 `pingan`，因此安装到：

```text
pets/pingan/animations/work_finish_walk/
pets/pingan/animations/work_finish_lie_down/
```

现有宠物包要求所有普通动作帧等于包级画布；`pingan` 的包级画布是 `192 × 208`，本次素材是 `256 × 224`。为了避免降质，动画定义扩展两个可选字段：

```json
{
  "work_finish_walk": {
    "path": "animations/work_finish_walk",
    "scope": "fullscreen",
    "canvas": {"width": 256, "height": 224},
    "fps": 10,
    "loop": true
  },
  "work_finish_lie_down": {
    "path": "animations/work_finish_lie_down",
    "scope": "fullscreen",
    "canvas": {"width": 256, "height": 224},
    "fps": 10,
    "loop": false
  }
}
```

- `scope` 缺省为 `pet`，保持现有宠物包兼容。
- 只有 `scope: fullscreen` 的动作可以声明独立 `canvas`。
- 包校验器按动作独立画布验证全屏帧，普通动作仍严格使用包级画布。
- 普通桌宠状态机过滤全屏作用域动作，不能通过普通事件误播放。
- 动画编辑器仍列出全屏作用域动作，并使用“下班提醒 · 走路循环”和“下班提醒 · 躺下过渡”作为显示名称。

原图是 `2048 × 672` 的 `8 × 3` 网格，每格 `256 × 224`：

- 第一行 8 帧为走路循环。
- 第二行前 7 帧为站立到趴下的过渡。
- 第三行前 6 帧为趴卧到翻身躺下的收尾。
- 共导出 21 张 `256 × 224` RGBA PNG，并保留透明背景。

`work_finish_lie_down` 的最后一帧是最终保持帧。全屏播放器在一次性动作结束后保持该帧；普通动画时长编辑器不为“无限保持”另设时长。

### ZIP 与文件夹导入

托盘菜单或动画管理入口提供“导入下班动画…”，接受标准 ZIP 或本地文件夹。两种来源使用同一包结构：

```text
work-finish/
├─ manifest.json
├─ walk/
│  ├─ 001.png
│  └─ ...
├─ lie-down/
│  ├─ 001.png
│  └─ ...
└─ preview.png
```

`preview.png` 可选。导入 manifest 声明名称、两个阶段的相对目录、FPS 或逐帧时长、帧画布和可选地面锚点。导入器执行以下流程：

1. 用户选择 ZIP 或文件夹，并明确看到目标宠物名称。
2. 校验 manifest、帧数量、自然排序、画布尺寸、RGBA 可读性和所有相对路径。
3. 显示动画名称、两个阶段的帧数、预计时长和可用预览。
4. 已存在两个专用动作时明确询问是否替换。
5. 将帧写入同包临时目录，生成候选 `pet.json` 并执行完整宠物包校验。
6. 全部通过后原子替换两个动作目录和 `pet.json`；任一步失败都恢复原动画与原配置。
7. 导入成功后立即重载当前宠物，不要求重启应用。

ZIP 导入必须拒绝绝对路径、`..` 路径穿越、符号链接、重复路径、异常压缩比和超出限制的文件数量或解压体积。文件夹导入只接受包目录内的常规文件，不跟随符号链接。导入器把素材复制进宠物包，不依赖原 ZIP 或源文件夹继续存在。

本次不提供精灵图交互切帧入口；用户给出的原始精灵图由项目内确定性工具切成标准导入结构或直接安装为内置 `pingan` 动作。

### 换宠回退

切换宠物时，下一次提醒重新解析当前宠物的资源，不沿用上一个宠物的形象：

1. 当前宠物有两个有效的 `scope: fullscreen` 专用动作时使用专属动画。
2. 没有专属动画时，走入阶段优先使用普通 `walk` 动作，没有则使用 `idle`。
3. 到达中央后优先使用普通 `sleep` 动作，没有则保持 `idle`。
4. 当前宠物连可用的普通帧也无法加载时，仅显示左上角操作面板。

不使用其他宠物的专属动画作全局兜底。

## 架构

### `petnest.core.work_finish_state`

提供与 Qt 无关的状态模型和时间计算。状态包括：

- `waiting`：当天实际下班时刻之前。
- `prompting`：全屏提醒正在显示。
- `overtime`：用户已选择继续加班，等待下一小时节点。
- `finished`：当天已下班，不再提醒。

该模块负责：

- 计算累计加班时长。
- 计算下一个相对实际下班时刻的整小时提醒节点。
- 判定应用启动或唤醒时是否需要补播。
- 判定提醒是否已达到 30 分钟超时。
- 丢弃不属于当前有效工作日的旧状态。

所有计算以绝对时间为依据，显示计时器只负责刷新，不依赖定时器回调次数累加。

### 宠物包模型、校验与导入

`AnimationDefinition` 增加动作作用域与动作级画布。`PackageValidator` 仅对明确标记为全屏的动作接受独立画布，并继续执行现有路径、帧和逐帧时间线校验。`PetStateMachine` 只接收普通宠物作用域动作。

新增导入服务负责 ZIP/文件夹读取、限额、安全校验、候选包生成、原子替换和失败回滚。UI 对话框只负责文件选择、摘要预览、目标确认与替换确认，不承担文件写入逻辑。

### `petnest.ui.work_finish_reminder`

由两个顶层窗口组成：

- `WorkFinishAnimationWindow`：透明、无边框、置顶、无焦点且鼠标穿透，覆盖目标屏幕的完整几何区域并绘制宠物帧。
- `WorkFinishControlWindow`：位于目标屏幕可用区域左上角，保持在动画之上，提供两个按钮和超时剩余时间。

动画播放器包含三个阶段：

1. 循环走路帧，同时将画布从右侧移到中央。
2. 在中央播放一次躺下过渡。
3. 保持最终帧。

窗口关闭时停止所有动画和显示定时器。屏幕在提醒前不可用时依次回退到桌宠当前屏幕和主屏幕。

### `petnest.ui.animation_editor_dialog`

现有编辑器直接复用，不建立第二套时长编辑页面。全屏动作与普通动作一起列出，但带有明确的“全屏提醒”用途标签：

- `work_finish_walk` 可使用“按总时长播放”调整一轮步态循环时长，或逐帧编辑停留时间。猫从右侧移动到中央的约 4 秒位移保持固定，走入期间按编辑后的节奏循环步态。
- `work_finish_lie_down` 可调整完整躺下过渡的总时长或每帧时长。
- 最终保持帧在动作时间线中仍有正常播放时长；动作结束后由全屏窗口无限保持，不把保持阶段写成超大毫秒值。

编辑器继续通过现有原子配置更新路径把 `frame_durations_ms` 保存到 `pet.json`。

### `petnest.ui.work_countdown`

现有 `WorkCountdownWindow` 继续负责固定与弹性排班的实际下班时刻计算，并驱动工作结束状态：

- `waiting` 显示现有“距离下班 HH:MM:SS”。
- `prompting` 和 `overtime` 显示“你已加班 HH:MM:SS”；首次提醒尚未选择时保持现有“下班啦 🎉”，避免在用户未确认前假定加班。
- `finished` 显示“下班啦 🎉”。
- 状态要求展示提醒时，向应用装配层发出一次请求，不直接创建顶层窗口。

### `petnest.app.PetNest`

应用装配层负责：

- 创建全屏动画与控制窗口。
- 将倒计时提醒请求连接到提醒窗口。
- 将两个按钮的选择传回状态控制器。
- 在换宠后更新动画资源解析目标。
- 打开 ZIP/文件夹导入对话框，并在成功后重载当前宠物。
- 在应用退出时关闭提醒窗口。
- 通过 `SettingsManager` 原子保存状态。

## 持久化

用户设置新增足够恢复当天会话的字段：

- 状态所属工作日期。
- 实际下班时刻。
- `prompting`、`overtime` 或 `finished` 状态。
- 当前提醒开始时刻，用于恢复 30 分钟剩余时间。
- 下一小时提醒时刻。

设置模型升级一个 schema 版本，并为旧设置提供空状态默认值。读取到损坏、矛盾或未来版本的工作结束状态时，只清理该状态并回到当天排班计算，不影响其他设置。

应用在 `prompting` 状态退出后重启时继续原 30 分钟窗口；若绝对超时时刻已经过去，则直接进入 `finished`。应用在 `overtime` 状态重启时从保存的实际下班时刻恢复累计时长。

## 错误处理

- 全屏作用域动作配置、目录或 PNG 损坏时记录警告，并按当前宠物的普通动作回退。
- ZIP/文件夹导入失败时保留现有动作目录与 `pet.json`，向用户显示可操作的失败原因。
- 动画资源完全不可用时仍显示操作面板，倒计时与状态转换正常工作。
- 重复计时器刷新、系统休眠恢复和同一秒内的多次刷新不能重复创建提醒窗口。
- 目标屏幕断开时关闭旧动画窗口，并在可用屏幕重新定位当前提醒。
- 关闭应用时先停止倒计时与提醒定时器，再销毁两个顶层窗口，不能留下置顶残影。

## 测试与验收

### 状态单元测试

- 固定排班与弹性打卡在准确的实际下班时刻进入 `prompting`。
- 同一节点只请求一次提醒。
- “再加一会”从原实际下班时刻累计，并计算正确的下一小时节点。
- “下班”和 30 分钟超时都进入 `finished`。
- 每小时继续加班不会重置累计时间。
- 启动或唤醒错过节点时只补播一次。
- 状态在重启后恢复，并在下一有效工作日失效。
- 设置迁移为旧配置补齐默认字段。

### 资源与 UI 测试

- `pingan` 的两个全屏作用域动作能加载 8 帧走路与 13 帧躺下过渡，并保留 `256 × 224` 动作画布。
- 普通动作仍被强制为包级画布，全屏作用域动作不会进入普通宠物状态机。
- 动画时长编辑器列出两个全屏动作，并把总时长或逐帧时长保存回 `pet.json`。
- 非 `pingan` 宠物按 `walk/idle` 与 `sleep/idle` 回退。
- 非法路径、空帧和尺寸不一致触发安全回退。
- ZIP 与文件夹导入生成等价安装结果；路径穿越、符号链接、异常压缩包和部分写入均被拒绝或回滚。
- 替换已有下班动画需要确认，取消或失败时原资源字节保持不变。
- 动画窗口使用桌宠所在屏幕完整几何区域，帧宽约为屏幕的 92%。
- 动画窗口鼠标穿透，控制窗口按钮可交互并位于屏幕左上角。
- 关闭、换宠和应用退出会停止定时器并隐藏两个窗口。

### 素材与集成验收

- 确认切出 8 帧走路、7 帧趴下、6 帧躺卧，共 21 帧。
- 确认所有输出为 `256 × 224` RGBA PNG，透明背景未被黑底替代。
- 生成接触表和动画预览，检查帧顺序、透明边缘、锚点跳动和尺寸变化。
- 在 Qt 画面中验证右侧走入、中央躺下、92% 屏宽缩放和左上角按钮层。
- 运行相关测试、完整测试套件和 Windows 构建检查。

## 非目标

- 本次不为其他宠物制作新的专属躺下素材。
- 本次不在设置页增加动画大小、速度或提醒间隔选项。
- 本次不提供下班动画的精灵图交互切帧入口。
- 本次不提供下班动画包导出或远程上传。
- 本次不跨设备同步是否已下班或累计加班状态。
