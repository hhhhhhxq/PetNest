# PetNest 宠物旁轻量便签本设计规格

## 1. 目标

为 PetNest 增加一个可选的轻量便签本。用户开启功能后，鼠标悬浮宠物会在现有互动道具入口旁看到便签本入口；点击后在宠物附近展开一本小笔记本，再次点击同一入口关闭。

它用于随手记录灵感、待发送文字、项目总结、零碎信息、待办清单和提醒事项。功能保持本地、轻量、快速，不演变为完整知识库或团队协作产品。

最终交互与视觉原型是：

`/.superpowers/brainstorm/notes-20260829/content/notebook-final-v1.html`

实现必须以该原型为视觉基准，并按本文验收清单逐项复核。

## 2. 已确认的产品边界

- 提供三种独立页型：普通便签、待办清单、提醒事项。
- 不提供顶部应用标题，不显示“我的便签本”“便签功能”“提醒事项”等装饰性标题。
- 不在第一版提供搜索、云同步、团队共享、图片附件或富文本。
- 不提供固定图钉；笔记本始终依附宠物并随宠物移动、跨屏和避让屏幕边缘。
- 笔记本打开后不会因鼠标移出、切换应用或失去焦点而自动关闭；再次点击悬浮入口才关闭，`Esc` 也可关闭。
- 窗口保持在普通应用窗口上方，但不抢焦点、不覆盖系统安全界面，也不主动盖住全屏应用。
- 所有内容只保存在本机，不上传、不写入日志。

## 3. 功能开关与悬浮入口

### 3.1 设置

在设置中心“显示与窗口”页新增“宠物旁便签本”开关：

- 字段：`quick_notebook_enabled`
- 默认值：`false`
- 关闭时不显示入口，并关闭已打开的便签本窗口；数据仍保留。
- 再次开启后恢复上次页型和页码，不自动打开窗口。

### 3.2 悬浮入口

复用现有 `InteractionItemToolbox` 顶层悬浮工具窗，不创建第二个会互相抢占 hover 状态的独立窗口。

- 现有互动道具按钮：`44 × 44`，图标 `25 × 25`。
- 新便签本按钮：`44 × 44`，图标 `25 × 25`。
- 两按钮水平间距：`6px`。
- 默认透明背景；hover、pressed、打开状态使用 `rgba(255, 242, 236, 190)`。
- 图标主描边：`#A84F30`；纸面填充：`#F1B292`。
- 图标使用现有 `lucide_icon` 矢量渲染管线新增 `notebook` 图形，不能使用 Emoji 或与现有道具按钮风格不同的位图。
- 提示与无障碍名称均为“便签本”。

当没有互动道具时，只显示便签本入口；当便签功能关闭且没有互动道具时，整个悬浮工具窗隐藏。

## 4. 笔记本窗口与位置

新增独立、无边框、透明顶层 `QuickNotebookWindow`。窗口需要接受键盘焦点以编辑文字，但显示时不主动抢走当前应用焦点；用户点击编辑区后才获得输入焦点。

- 自然内容宽度：`390px`，在小屏幕或大字体下收缩，不产生横向滚动。
- 使用设备无关坐标，不手动乘除 DPI。
- 默认出现在宠物右侧；空间不足时依次尝试左、下、上。
- 必须避开宠物、悬浮入口、倒计时、打卡卡片和系统可用区域外空间。
- 宠物移动或跨屏时重新定位；笔记本不允许独立拖离宠物。
- 宠物被隐藏、下班全屏提醒占用宠物或应用退出时，笔记本同步隐藏。

## 5. 视觉规格

### 5.1 整体

| 用途 | 值 |
| --- | --- |
| 纸面 | `#FFFDFA` |
| 纸内层 | `#FFFEFB` |
| 外边框 | `#DDCFC2` |
| 内边框 | `#EEE3DA` |
| 主文字 | `#4B4641` |
| 次文字 | `#81736A` |
| 主操作 | `#D98663` |
| 普通便签页签 | `#9E8ACB` |
| 待办清单页签 | `#75A876` |
| 提醒事项页签 | `#D39C54` |

- 外层圆角 `17px`，纸内层圆角 `13px`，按钮圆角 `9px`。
- 无线圈、无固定横线、无顶部工具栏、无搜索框。
- 正文通过约 `1.7` 倍行距、段落留白和当前编辑行浅暖色提示保证可读性。
- 删除按钮位于当前页右上角，使用统一线性垃圾桶图标。

### 5.2 仿真侧页签

- 三个页签固定在纸页左边缘外侧，右边缘与纸页左边缘允许最多 `1px` 覆盖以隐藏接缝。
- 页签绝不能压入正文区或因活动页签变宽带动其他页签错位。
- 非活动页签 `43 × 43px`，只显示图形；活动页签宽 `88px`，向左伸展并显示“普通”“待办”或“提醒”。
- 页签间距 `8px`，顶部起点距纸页顶部 `28px`。
- 页签使用轻微左下投影和折角轮廓，不增加线圈、封皮纹理或其他装饰。

### 5.3 底部操作栏

- 左侧：`目录 · 当前页 / 当前类型总页数`。
- 中部：上一页、下一页；仅在当前页型内翻页，到达首尾时禁用对应按钮。
- 右侧：`＋ 新建`，创建当前页型的新页。
- 所有按钮必须完全位于窗口内部；禁止使用会裁切按钮的固定总高度。

## 6. 标题规则

标题不是必填项，也不在新建时弹出单独对话框。

1. 用户填写自定义标题时显示该标题。
2. 未填写时：
   - 普通便签取正文第一行；
   - 待办清单取第一条非空待办；
   - 提醒列表取第一条非空提醒标题。
3. 内容仍为空时显示轻量占位：`无标题便签`、`新待办清单`、`新提醒列表`。

自动标题只用于显示，不回写成用户自定义标题；正文首行变化后自动标题同步变化。

## 7. 三种页型

### 7.1 普通便签

- 可选标题、纯文本正文、最多 5 个自由标签。
- 适合灵感、待发送文字、项目总结和零碎记录。
- 编辑内容 `500ms` 防抖后自动保存；关闭窗口或切页时立即刷新未写入的数据。

### 7.2 待办清单

- 可选标题和有序待办项。
- 每项包含文本、完成状态、创建时间和完成时间。
- 支持新增、编辑、勾选、取消勾选和拖动排序。
- 顶部显示完成数与进度；已完成项保留在原列表中并降低视觉权重。

### 7.3 提醒事项

- 一个提醒列表页可包含多条提醒。
- 每条包含标题、启用状态、触发时间和重复规则。
- 第一版重复规则：仅一次、每天、每周指定星期。
- 到期时在宠物旁显示持久提醒卡片，不播放声音、不显示全屏层；卡片提供“完成”“稍后 10 分钟”“打开便签”。
- 宠物当前隐藏时使用系统托盘通知作为降级；用户重新显示宠物后仍可从提醒列表查看到期状态。

## 8. 目录、页数和翻页

- 点击侧页签后，目录、当前页、总页数和翻页范围全部切换到该页型。
- 目录只列出当前页型，不混入另外两类。
- 默认按最后修改时间倒序；用户打开一页不会改变修改时间。
- 目录项显示派生标题和当前页序号；点击后切换到对应页并关闭目录层。
- 应用恢复上次选中的页型和页 ID；不存在时回退到该类型第一张，再不存在时创建空白页。

## 9. 删除、清空和恢复

- 右上角垃圾桶只删除当前页，必须二次确认。
- 目录底部提供“清空全部<当前页型>…”，只清空当前侧页签对应的页面；确认框必须列出当前类型和数量，另外两种页型不受影响。
- 删除和清空均先进入本地回收站，保留 7 天；目录中提供“回收站”入口，可恢复或永久删除。
- 7 天后在成功加载数据后清理过期项目；清理失败不影响主数据加载。
- 空类型仍保留一张新建空白页，不让主界面进入无对象状态。

## 10. 数据模型与存储

便签内容不写进 `settings.json`，单独保存在用户配置目录：

`quick-notebook.json`

根结构：

```json
{
  "schema_version": 1,
  "last_type": "note",
  "last_page_id_by_type": {},
  "pages": [],
  "trash": []
}
```

页面公共字段：`id`、`type`、`custom_title`、`created_at`、`updated_at`。普通便签额外保存 `body`、`tags`；待办页保存 `items`；提醒页保存 `reminders`。

- 使用同目录临时文件、flush、fsync 和 replace 原子保存。
- JSON 损坏时保留带时间戳备份并创建空数据集，不覆盖损坏原件。
- 每次写入保存完整快照，第一版不引入数据库。
- 正文、标题和提醒文字不进入普通应用日志。

## 11. 组件边界

### `core/quick_notebook_store.py`

负责模型校验、标题派生、增删改、翻页顺序、回收站和原子持久化；不依赖 Qt 控件。

### `core/quick_notebook_reminders.py`

负责计算下一次触发时间、完成、稍后提醒和重复推进；输入输出为数据模型，不直接绘制 UI。

### `ui/quick_notebook_window.py`

负责最终原型对应的窗口、侧页签、三类编辑页、目录层、确认层、翻页和自适应定位。

### `ui/quick_notebook_reminder.py`

负责宠物旁到期提醒卡片与用户操作信号。

### 现有悬浮工具窗

在现有互动道具悬浮窗中增加便签入口和信号，保持单一 hover 生命周期；不复制宠物进入/离开计时器。

### `app.py`

只负责创建 store、窗口、提醒协调器，连接信号，应用设置，并在宠物移动、隐藏和退出时同步生命周期。

## 12. 数据流

1. 用户悬浮宠物，现有悬浮工具窗显示道具箱和便签本入口。
2. 点击便签本入口，控制器加载上次页型与页面，定位并显示窗口。
3. 编辑控件产生变更，窗口把结构化数据交给 store；store 防抖或立即原子保存。
4. 切页、切类型和目录操作只通过页面 ID 更新 UI，不复制数据对象。
5. 提醒协调器读取启用提醒的下一次触发时间，到期后发出结构化事件；提醒卡片不直接修改文件。
6. 完成或稍后操作通过 store 更新提醒，再重新计算下一次触发。

## 13. 错误与边界处理

- 屏幕过窄：优先缩小内容宽度，正文换行，底部“新建”按钮可换到下一行；禁止横向滚动和裁切。
- 字体或 DPI 变化：重新计算自然尺寸与位置，不复用旧屏幕尺寸。
- 宠物靠边：窗口翻到可用方向；侧页签仍完整处于屏幕可用区域。
- 保存失败：保留编辑器内容，显示非阻塞错误提示并允许重试；不得假装已保存。
- 提醒时间无效：禁用该条并在列表内标出错误，不拖垮其他提醒。
- 系统时间跳变或休眠恢复：重新扫描已到期但未处理的提醒，每条只触发一次。

## 14. 测试与一比一复核

### 14.1 核心测试

- 三类页面序列化、反序列化和损坏数据降级。
- 自定义标题优先与三类自动标题规则。
- 当前类型翻页、首尾禁用、目录范围和页数。
- 新建、删除、清空、恢复和 7 天过期清理。
- 提醒的一次、每天、每周、完成和稍后 10 分钟计算。
- 原子保存失败不会破坏旧文件。

### 14.2 Qt 交互测试

- 悬浮入口为两个 `44 × 44` 按钮，图标均为 `25 × 25`，间距 `6px`。
- 没有互动道具时仍可显示便签入口。
- 点击入口打开，再次点击关闭；鼠标离开不关闭笔记本。
- 三侧页签切换正确，目录和页数只属于当前类型。
- 删除、清空确认和回收站恢复可用。
- 窄屏、大字体、多 DPI 下无横向溢出、按钮无裁切。
- 宠物移动、隐藏、跨屏和关闭时生命周期正确。

### 14.3 视觉逐项复核

实现完成后必须渲染实际 Qt 窗口截图，并与最终原型逐项对照：

1. 两个悬浮入口的顺序、尺寸、间距、暖色图标和 hover 底色。
2. 无线圈、无顶部应用标题、无搜索、无固定图钉。
3. 外层与内层圆角、纸色、边框色、阴影和留白。
4. 三个侧页签的颜色、折角、间距、活动宽度和 `1px` 接缝覆盖。
5. 标题、正文、当前行提示、标签、待办和提醒排版。
6. 垃圾桶位置与图标风格。
7. 底部目录、当前类型页数、翻页和新建按钮。
8. 目录、删除确认、全部清空确认和回收站子视图。
9. `100%`、`125%`、`150%` DPI 与窄屏状态下的完整显示。

任何明显偏差都必须在交付前修正；不能仅以功能测试通过代替视觉验收。

## 15. 非目标

- 不实现全文搜索。
- 不实现 Markdown、富文本、图片、附件和剪贴板历史。
- 不实现账号、云同步、多人协作或跨设备同步。
- 不实现便签窗口独立拖拽、固定位置或单独的窗口置顶按钮。
- 不修改宠物资源包格式。
