# 动画编辑器帧预览设计

## 目标

让用户在调整逐帧时长时，能同时确认单帧内容与完整动作节奏。

## 布局

- 动作列表保留在顶部，用于选择要编辑的动画。
- 逐帧模式使用左右分栏：左侧为带缩略图、帧号和毫秒输入框的帧列表；右侧为透明背景的大尺寸循环预览。
- 总时长模式隐藏逐帧列表，但继续显示右侧整体预览。

## 交互

- 任一时长输入变更后，预览立即按新的时间线重启循环。
- 预览自动循环当前动作；正在播放的帧在左侧列表高亮。
- 点击缩略图暂停自动预览并显示所选帧；再次点击播放按钮恢复循环。
- 动作切换、模式切换或关闭窗口时，停止预览计时器并释放缩略图图像。

## 错误处理与测试

- 无法读取单帧缩略图时，该行显示占位文本，不影响其他帧或时长编辑。
- 测试覆盖：缩略图对应正确帧、时长变更重启预览、预览按当前时间线推进、关闭窗口停止计时器。
