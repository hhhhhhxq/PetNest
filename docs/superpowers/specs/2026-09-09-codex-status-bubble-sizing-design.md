# Codex 状态气泡自适应尺寸设计

## 目标

Codex 状态气泡应优先按消息的单行自然宽度展示，避免短消息被强制撑宽或过早换行。只有文字本身超过最大文本宽度时才换行。

## 尺寸规则

- 所有状态共用同一套文本尺寸算法，不再由 compact、review、waiting 或 failed 状态直接决定是否换行。
- 使用当前字体度量计算消息的单行自然宽度。
- 自然宽度不超过 260 个逻辑像素时，标签采用自然宽度并保持单行。
- 自然宽度超过 260 个逻辑像素时，标签宽度限制为 260 个逻辑像素并启用换行。
- 完整提示保留现有左 11、上 7、右 7、下 7 的布局边距、7 px 控件间距及关闭按钮。
- compact 提示隐藏关闭按钮，并使用左右各 16 px、上下各 7 px 的对称布局边距。

## 状态切换

每次设置消息时重新计算文本宽度与换行状态，不能沿用上一个状态的最小宽度、固定宽度或换行属性。compact 与完整提示切换时，同时恢复各自的布局边距和关闭按钮可见性。

## 测试

- 短 compact 文案按单行自然宽度展示，左右边距均为 16 px。
- 短完整通知按单行自然宽度展示，不因 `wordWrap` 的尺寸提示提前换行。
- 超过 260 px 的长通知限制到 260 px 并换行。
- compact 与完整通知往返切换后，宽度、换行和边距均按当前消息重新计算。
- 现有气泡交互、屏幕边界及宠物窗口集成测试继续通过。
