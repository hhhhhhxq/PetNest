# 普通便签引导、保存提示与归类面板设计

## 目标

在不改动待办、提醒页面和便签保存模型的前提下，修正普通便签页的重复提示、保存浮层和分类交互，使界面与已确认的 A 方案 v2 原型一致。

视觉基准：`.superpowers/brainstorm/1462-1789528762/content/category-panel-option-a-v2.html`。

## 范围

本次只修改普通便签页：

1. 空白正文只显示一处居中引导。
2. 保存成功提示恢复为正文右下角暖灰色圆角浮层。
3. 未选择分类时，“归类”按钮右侧不显示空绿色背景。
4. “归类”展开为浮动标签盘，支持选择、移除、创建和复用分类。

待办清单、提醒列表、目录、删除、翻页、存储结构和自动保存时机保持不变。

## 空白提示

- `QPlainTextEdit` 不再设置与空白引导重复的多行占位文字。
- 空白页只由正文视口中央的引导层显示：
  - 主句：`开始写点什么吧`
  - 辅助说明：`第一行会自动成为标题`、`也可以点击上方标题自定义`
- 用户输入正文后引导立即隐藏；正文再次为空时恢复。
- 引导层不接收鼠标事件，不影响点击正文输入。

## 保存提示

- 成功提示显示在正文区域右下角，不参与布局，不压缩正文。
- 文案为 `✓ 已保存到本机`。
- 背景 `#F1E8E0`，文字 `#786B63`，边框 `#E5D8CE`，圆角 10 px，内边距约 6×9 px。
- 成功提示约 2 秒后自动消失。
- 保存失败仍使用常驻错误提示和重试按钮，直到重试成功。
- 保存提示不得新增影响 Windows 半透明窗口重绘的纸层图形效果。

## 归类入口与摘要

- 收起状态按钮文案为 `归类`，展开状态为 `收起`。
- 按钮右侧只显示当前便签已选择的分类标签。
- 当前便签没有分类时，摘要控件必须完全隐藏，不能保留背景、内边距或占位宽度。
- 摘要标签使用浅绿色背景和深绿色文字，保持轻量，不显示删除按钮。

## 浮动标签盘

- 面板锚定在归类行上方，覆盖正文底部，不改变正文与页脚的布局高度。
- 面板包含：
  1. 标题 `选择分类` 与计数 `已选 n / 5`。
  2. “当前便签”区域：已选标签以浅绿色按钮显示，带 `×` 移除入口。
  3. “最近使用”区域：展示最多 8 个未选候选标签。
  4. 新分类输入框与“添加”按钮；按 Enter 等同于点击添加。
- 点击未选标签会加入当前便签；点击已选标签的 `×` 只从当前便签移除。
- 每张便签最多选择 5 个分类；达到上限后阻止继续选择，并在面板内显示简短说明。
- 分类名称去除首尾空格，空名称不创建，重复名称直接复用，名称最长 10 个字符。

## 分类来源与生命周期

- 不新增独立、永久的分类注册表。
- 候选分类从所有未删除普通便签的 `tags` 动态汇总。
- 候选按最近编辑过的便签优先，再去重；面板最多显示 8 个未选分类。
- 某个分类不再被任何普通便签使用后，会自然从候选区消失，不产生孤立数据。
- 回收站中的便签不参与候选分类汇总。

## 数据与保存

- 继续复用 `NotebookPage.tags`，不改变 JSON schema。
- 选择、移除和创建分类后更新隐藏的分类编辑值，并走现有 500 ms 自动保存流程。
- 切页、关闭和删除前仍由现有同步刷新逻辑保证当前编辑已保存。
- 分类面板只负责编辑当前普通便签的 `tags`，不修改其他便签。

## 可访问性与键盘

- “归类/收起”、候选分类、已选分类移除按钮和“添加”按钮均可通过键盘聚焦和触发。
- 分类按钮提供明确的 accessible name；已选标签移除按钮使用 `从当前便签移除分类：<名称>`。
- Enter 创建分类；Escape 关闭面板并把焦点返回“归类”按钮。

## 测试与验收

- 空白正文只存在一个可见引导；输入后隐藏，清空后恢复。
- 保存成功浮层具有指定背景、边框、圆角和位置，并按时消失。
- 无分类时摘要控件隐藏；有分类时才显示绿色标签。
- 候选分类从现存普通便签动态汇总，排除回收站和已选项，最多显示 8 个。
- 选择、移除、创建、重复名称、空名称、10 字符限制和 5 个上限均有自动化测试。
- 切页后当前便签分类正确，不串页；保存并重载后分类保持。
- 100%、125%、150% 缩放下，浮层不越过纸张边界，不遮挡页脚。
- 通过真实 Windows 窗口截图检查保存提示、空摘要和浮动标签盘的视觉还原。
