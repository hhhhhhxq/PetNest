# PetNest 设置中心与快捷菜单重设计规格

## 1. 目标

在不改变互动窗口、宠物右键菜单和倒计时气泡既有体验的前提下，完成 PetNest 设置中心、托盘菜单、精灵图导入向导和动画时长编辑器的统一重设计，并补充弹性打卡与鼠标大小调节能力。

视觉方向：PetNest 暖色奶油风，精致、高级、简约，使用轻量半透明卡片、细边框和柔和阴影模拟磨砂玻璃质感。

## 2. 已确认的边界

### 2.1 窗口关系

| 入口 | 打开的窗口 | 本轮处理 |
| --- | --- | --- |
| 设置… | 设置中心 | 一个窗口，左侧分类导航 |
| 鼠标样式… | 设置中心的“鼠标与行为”分类 | 仍保留独立菜单入口，但不再创建旧独立窗口 |
| 互动… | 现有互动窗口 | 保持原样，只做回归验证 |
| 导入精灵图… | 独立导入向导 | 保持独立，统一视觉风格 |
| 编辑动画时长… | 独立动画编辑器 | 保持独立，统一视觉风格 |

同一窗口已有实例时，入口只激活已有实例，不重复创建。互动窗口的设备、发送、预览和远程伙伴流程不在本轮范围内。

### 2.2 数据兼容与新增字段

旧设置字段继续保留并可读取：`work_countdown_enabled`、`work_start_time`、`work_end_time`、`daily_work_end_times`、倒计时外观字段以及现有鼠标字段。新增字段如下：

| 字段 | 类型 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `cursor_scale` | `int` | `100` | 自定义鼠标大小，允许 `80/100/125/150` |
| `work_schedule_mode` | `str` | `"fixed"` | `fixed` 固定时段，`elastic` 弹性打卡 |
| `clock_in_start_time` | `str` | `"09:30"` | 弹性打卡允许开始时间 |
| `clock_in_end_time` | `str` | `"10:00"` | 弹性打卡允许结束时间 |
| `work_duration_minutes` | `int` | `540` | 弹性打卡后的工作时长，默认 9 小时 |
| `clock_in_date` | `str | None` | `None` | 最近一次打卡日期 |
| `clock_in_time` | `str | None` | `None` | 最近一次打卡时间 |

设置 schema 递增迁移至新版本。旧设置缺少新字段时使用默认值，不改变其他字段含义。

### 2.3 设置中心不重复承载互动设置

局域网互动开关、远程伙伴开关、昵称、设备列表和发送操作继续由现有互动窗口负责。设置中心不创建“互动与连接”分类，也不重复显示这些控件。

### 2.4 菜单职责

- 托盘右键菜单负责应用级管理、宠物库、设置和退出。
- 宠物右键菜单负责当前宠物的即时操作。
- 托盘移除没有操作价值的“动画播放中”信息，只保留“当前宠物：名称”等有用状态。
- 宠物右键菜单的布局、样式、图标、项目、顺序和动态状态全部保持原样。

## 4. 信息架构

### 4.1 设置中心分类

左侧无装饰性图标，仅显示文字分类，当前项使用浅珊瑚色高亮：

1. **显示与窗口**：桌宠大小、始终置顶、启用鼠标交互。
2. **鼠标与行为**：跟随鼠标、跟随时宠物大小、自定义鼠标样式、鼠标样式、鼠标大小吸附滑块、角色预览与覆盖说明。
3. **系统空闲**：启用空闲动作、无操作后无聊、无操作后睡觉。不显示“时间关系会自动校验”之类的解释性声明。
4. **工作倒计时**：显示开关、工作日选择、固定时段/弹性打卡模式、对应时间设置、倒计时外观高级设置。
5. **应用与更新**：当前版本、检查程序更新。

设置页不展示运行状态示例。倒计时背景选择保留在“工作倒计时”的高级设置中。

## 5. 工作倒计时与弹性打卡

### 5.1 工作日只选择一次

工作倒计时页只保留一个工作日选择模块，位于模式选择之前。周一至周日均可勾选，因此周六或周日勾选后会正常参与当前模式的计算；未勾选的日期显示为休息日。

不再在“规律休息”和“灵活安排”中重复放置工作日选择，也不再维护“例外下班时间”列表。

### 5.2 固定时段模式

`fixed` 模式使用统一的上班时间和下班时间，工作日共用这组时间。界面提供快捷操作：工作日全选、周末设为休息日、恢复默认。

保存时继续同步写入旧字段：`work_start_time`、`work_end_time` 和所选工作日对应的 `daily_work_end_times`，从而兼容旧的倒计时计算与设置文件。

### 5.3 弹性打卡模式

`elastic` 模式使用：

- 允许打卡开始时间；
- 允许打卡结束时间；
- 打卡后工作时长。

选择弹性打卡后，打卡模式自动生效，不再额外增加一个容易混淆的“启用打卡”开关。

例如允许 `09:30–10:00` 打卡、工作时长 9 小时：

- `09:30` 及之前记录，按 `09:30` 计算，下班 `18:30`；
- `09:40` 记录，按 `09:40` 计算，下班 `18:40`；
- `10:00` 及之后记录，按 `10:00` 计算，下班 `19:00`。

也就是先将记录时间限制在允许窗口内，再加上工作时长。时间窗口输入必须满足开始时间早于结束时间，工作时长为正数。

### 5.4 独立打卡卡片

工作倒计时开启且模式为弹性打卡时：

- 在已选工作日、达到允许打卡开始时间后，宠物旁显示独立的浅色打卡卡片；
- 卡片不使用倒计时气泡背景，不挤入倒计时气泡，不改变倒计时气泡的布局和绘制逻辑；
- 未打卡状态有两个明确分离的控件：可编辑时间输入框（默认当前时间，右侧保留下拉箭头）和“打卡”按钮，示例文案为“09:40   打卡”；
- 用户可以先调整时间再点击打卡；
- 打卡成功后卡片隐藏，原倒计时气泡恢复显示下班倒计时；
- 当前日期、打卡时间持久化到设置文件，跨日或非工作日时自动视为无打卡记录；
- 在允许开始时间之前不显示打卡卡片。

倒计时气泡仍由现有 `PetWindow` 按原布局、皮肤、间距、尺寸和文字规则绘制。本轮只新增与之并列的独立打卡控件。

## 6. 交互与保存规则

- 设置中心打开时创建编辑副本，点击“应用并关闭”后才返回新设置；取消或关闭则丢弃修改。
- 关闭跟随鼠标时，跟随时宠物大小立即禁用并保留值。
- 鼠标大小滑块可自由拖动，松开后吸附到 `80%`、`100%`、`125%`、`150%`；关闭自定义鼠标样式时相关控件禁用并保留值。
- 关闭系统空闲动作时，两个时间控件禁用并保留值；调整时间时自动保证无聊时间小于睡眠时间，但不显示额外声明。
- 关闭工作倒计时时，工作日、模式、时间和外观控件禁用并保留值。
- 导入向导和动画编辑器保持独立保存语义和独立主操作。

## 7. 视觉规范

| 用途 | 颜色 |
| --- | --- |
| 主背景 | `#F7F1EA` |
| 玻璃卡片 | `#FFFDF9` |
| 次级卡片 | `#FBF7F2` |
| 主强调色 | `#D98663` |
| 强调浅底 | `#FFF0E8` |
| 主文字 | `#4B4641` |
| 次文字 | `#8F8680` |
| 分割线 | `#E8DED5` |
| 成功状态 | `#6D9A7A` |
| 错误状态 | `#C66C62` |

- 设置中心主窗口约 18px 圆角感，卡片 12px，控件 9px。
- 以 8px 为基础间距，保持宽松留白。
- 主按钮使用珊瑚橙，次按钮使用奶油白和细边框。
- 用半透明填充、细边框和轻阴影模拟磨砂，不依赖平台专属背景模糊 API。
- 新设计的托盘菜单使用 Qt 标准图标或现有轻量图标；宠物右键菜单保持原图标。
- 复用现有光标预览、倒计时皮肤和品牌资源。只有 Qt、文字和现有素材无法表达的图案才新增 `assets/ui/` 切图，并记录用途。

## 8. 非目标

- 不修改互动窗口的布局和业务流程。
- 不修改宠物右键菜单。
- 不修改倒计时气泡的绘制和布局。
- 不把导入向导或动画编辑器合并进设置中心。
- 不新增每天不同的上班时间配置。
- 不依赖真实系统背景模糊 API。

## 9. 验收标准

- 托盘菜单职责、顺序和分组符合本规格；不出现“动画播放中”。
- 宠物右键菜单的布局、样式、图标、项目、顺序和动态同步保持不变。
- “设置…”与“鼠标样式…”进入同一个设置中心，并能定位到对应分类。
- 设置中心五个分类可编辑并正确保存/取消；无奇怪的分类图标、无运行状态示例入口、无困惑性自动校验说明。
- 鼠标大小可在四个吸附节点间调整，旧设置文件缺少 `cursor_scale` 时按 100% 运行。
- 工作日只出现一次；固定模式和弹性打卡模式均正确处理周六、周日等被勾选日期。
- 弹性打卡按窗口钳制时间，打卡卡片独立于倒计时气泡，打卡后恢复原倒计时气泡。
- 导入向导、动画编辑器保持独立窗口且视觉令牌统一。
- 现有测试、编译检查、`git diff --check` 通过，并完成实际窗口或可替代的 Qt offscreen 视觉检查。
