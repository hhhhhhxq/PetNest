# PetNest 设置中心与快捷菜单重设计规格

## 1. 目标

在保留现有设置字段含义、宠物播放能力和互动业务流程的前提下，重新组织 PetNest 的设置中心和托盘右键菜单，补充鼠标大小设置，同时保护宠物右键菜单的现有体验，让用户能够：

- 快速找到设置；
- 理解每个选项的作用；
- 在设置有关联时看到明确的启用/禁用状态；
- 直接调整自定义鼠标大小，并理解当前大小；
- 区分“应用管理”“当前宠物快捷操作”和“长期偏好配置”；
- 在不同窗口中获得一致的暖色奶油风视觉体验。

本次重设计的视觉方向为：PetNest 暖色奶油风、精致高级、简约、轻量磨砂玻璃质感。

## 2. 已确认的边界

### 2.1 窗口关系

| 入口 | 打开的窗口 | 本轮处理 |
| --- | --- | --- |
| 设置… | 设置中心 | 重做为左侧分类导航窗口 |
| 鼠标样式… | 设置中心的“鼠标与行为”分类 | 合并原独立鼠标样式窗口 |
| 互动… | 现有互动窗口 | 保持现状，不重做布局和交互 |
| 导入精灵图… | 独立导入向导 | 保持独立，统一视觉风格并优化层级 |
| 编辑动画时长… | 独立动画编辑器 | 保持独立，统一视觉风格并优化层级 |

同一类窗口已经打开时，新的入口只激活已有窗口，不重复创建同一窗口实例。互动窗口的现有设备、发送、预览和远程伙伴流程不在本次范围内。

### 2.2 设置数据兼容

本次新增一个非敏感设置字段 `cursor_scale`，表示自定义鼠标样式的显示比例，取值为整数百分比 `80`、`100`、`125` 或 `150`，默认值为 `100`。旧设置文件缺少该字段时按 `100` 读取；迁移和保存不得改变其他设置字段的含义。若实现提高设置 schema 版本，迁移必须保持旧文件可读。

### 2.3 设置中心不重复承载互动设置

局域网互动开关、远程伙伴开关、昵称、设备列表和发送操作继续由现有互动窗口负责。新的设置中心不再创建“互动与连接”分类，也不重复显示这些控件。

### 2.4 菜单职责

- 托盘右键菜单负责 PetNest 应用级管理、宠物库管理、设置入口和退出。
- 宠物右键菜单负责当前宠物的即时操作。
- 详细参数只进入设置中心或专用工作窗口。
- 托盘菜单移除没有操作价值的“动画播放中”状态文案，只保留“当前宠物：名称”。

## 3. 功能页面数量

这里区分“实际实现的窗口”与“用于确认的设计图数量”，避免把同一个设置窗口的分类误认为多个窗口。

### 3.1 实际需要实现或改造的窗口：3 个

1. **设置中心**：一个窗口，包含五个左侧分类视图。
2. **导入精灵图向导**：一个独立窗口。
3. **动画时长编辑器**：一个独立窗口。

互动窗口仍然存在，但本轮不改造，因此不计入本轮重设计窗口数量。

### 3.2 需要确认的设计图：10 张

设计图按以下顺序逐张制作和确认。每张图确认后再制作下一张；任何一张被要求调整时，先修改并重新确认，不进入后续实现。

1. 托盘右键菜单
2. 设置中心：显示与窗口
3. 设置中心：鼠标与行为
4. 设置中心：系统空闲
5. 设置中心：工作倒计时
6. 设置中心：应用与更新
7. 导入精灵图：初始/自动识别状态
8. 导入精灵图：手动选择动作帧状态
9. 动画编辑器：按总时长编辑状态
10. 动画编辑器：逐帧编辑状态

互动窗口不制作新设计图，仅在实现完成后确认其未被误改。

## 4. 信息架构

### 4.1 设置中心分类

左侧固定显示以下分类，当前分类使用柔和珊瑚橙背景和深色文字高亮：

1. **显示与窗口**
   - 桌宠大小
   - 始终置顶
   - 启用鼠标交互
2. **鼠标与行为**
   - 跟随鼠标
   - 跟随时宠物大小
   - 自定义鼠标样式
   - 鼠标大小：80% / 100% / 125% / 150% 吸附滑块
   - 鼠标样式预览与覆盖角色说明
3. **系统空闲**
   - 启用系统空闲动作
   - 无操作后无聊
   - 无操作后睡觉
4. **工作倒计时**
   - 显示上下班倒计时
   - 安排方式：规律作息 / 灵活安排
   - 统一上班时间
   - 默认下班时间
   - 工作日选择与快捷操作
   - 选中工作日的独立下班时间调整
   - 可折叠的倒计时外观设置：主题、间距、最小宽度、卡片高度
5. **应用与更新**
   - 当前程序版本
   - 检查程序更新

当前未在设置页暴露的启动项、外部事件接口和宠物库路径不因本次视觉重排新增入口；它们继续遵循现有命令行或应用层行为。资源更新继续保留托盘入口，避免在设置中心重复动作。

### 4.2 托盘右键菜单

菜单顺序如下：

```text
PetNest
当前宠物：<名称>
────────────────
显示桌宠 / 隐藏桌宠
暂停动画 / 继续动画
始终置顶
跟随鼠标
────────────────
切换宠物  >
互动…
────────────────
宠物库  >
    导入精灵图…
    打开宠物文件夹
    刷新宠物列表
    编辑动画时长…
    重新加载当前宠物
────────────────
设置…
鼠标样式…
检查资源更新
────────────────
退出 PetNest
```

“鼠标样式…”仍保留独立入口，但打开设置中心并定位到“鼠标与行为”，不再创建旧的独立鼠标样式窗口。当前状态型动作根据运行状态动态改变文案或勾选状态。

### 4.3 宠物右键菜单

本轮不重新绘制、不重排、不换肤宠物右键菜单，继续保留当前实现中的原布局、样式、图标、项目、顺序和动态状态同步逻辑。实现阶段只做回归验证，确认托盘菜单重组没有影响它。其现有即时操作继续保持不变：

```text
<宠物名称> · <当前缩放比例>
────────────────
缩小
放大
恢复默认大小
────────────────
暂停动画 / 继续动画
始终置顶
跟随鼠标
────────────────
互动…
隐藏桌宠
设置…
```

菜单不放导入、打开文件夹、刷新宠物列表、资源更新和退出等应用管理动作。

## 5. 交互与状态规则

### 5.1 设置中心保存

- 打开时从当前 `Settings` 创建编辑副本。
- 点击“应用并关闭”才返回新设置并由应用层持久化。
- 点击“取消”或关闭窗口时丢弃未保存修改。
- 有未保存修改时关闭窗口，显示轻量确认，选项为“继续编辑”“放弃修改”。
- 关闭“跟随鼠标”时，跟随时宠物大小控件立即禁用并保留当前值。
- 鼠标大小使用可拖动滑块，松开后吸附到 `80%`、`100%`、`125%`、`150%` 四个节点；显示当前百分比，关闭自定义鼠标样式时整体禁用并保留当前值。
- 关闭“系统空闲动作”时，无聊和睡眠时间立即禁用并保留当前值。
- 关闭“显示上下班倒计时”时，工作时间和外观设置禁用并保留当前值。
- 系统空闲时间控件保持无聊时间小于睡眠时间；用户调整数值时自动将另一个值保持在合法范围，不额外显示“自动校验”说明。
- 工作倒计时提供“规律作息”和“灵活安排”两种编辑视图：规律作息用统一上班/默认下班时间和工作日选择快速生成日程；灵活安排仍使用统一上班时间，但只对需要例外的工作日编辑独立下班时间。提供“应用默认下班时间”“周末设为休息日”“恢复默认”等快捷操作。保存时继续写入现有 `work_start_time`、`work_end_time` 和 `daily_work_end_times` 字段，不新增每天独立上班时间字段。
- 自定义鼠标样式关闭时，样式选择、预览和角色覆盖信息禁用；“恢复系统默认样式”保持可用。

### 5.2 专用窗口

- 导入向导保留自动识别和手动选择两种模式，强化步骤标题、文件信息、预览区和底部主操作。
- 动画编辑器保留按总时长和逐帧编辑两种模式，强化动作列表、编辑区、实时预览和未保存状态。
- 两个专用窗口均使用独立的“取消”和主操作按钮，不与设置中心共享保存语义。
- 互动窗口只做回归确认，不主动调整其已有布局和交互。

## 6. 视觉规范

### 6.1 颜色

| 用途 | 建议颜色 |
| --- | --- |
| 主背景 | `#F7F1EA` |
| 玻璃卡片 | `#FFFDF9`，使用轻微透明度模拟磨砂层 |
| 次级卡片 | `#FBF7F2` |
| 主强调色 | `#D98663` |
| 强调浅底 | `#FFF0E8` |
| 主文字 | `#4B4641` |
| 次文字 | `#8F8680` |
| 分割线 | `#E8DED5` |
| 成功状态 | `#6D9A7A` |
| 错误状态 | `#C66C62` |

颜色是视觉令牌，具体对比度在实现时以系统浅色/深色调色板和可读性验证为准。

### 6.2 形状与间距

- 设置中心主窗口圆角感约 18px，卡片圆角 12px，控件圆角 9px。
- 主窗口使用宽松留白；卡片内标题、说明和控件按 8px 基准间距排列。
- 选中导航项使用浅珊瑚底色，不使用高饱和大色块。
- 主按钮使用珊瑚橙实底；次按钮使用奶油白底和细边框。
- 阴影只用于主窗口和浮层，使用低透明度，避免厚重拟物感。
- 磨砂效果使用半透明填充、细边框和轻阴影模拟，不依赖平台特定的真实背景模糊 API。

### 6.3 图标与素材

- 菜单中的常规操作优先使用 Qt 标准图标或轻量线性图标，不为每个菜单项新增位图。
- 上述菜单图标规则只适用于本轮重新设计的托盘菜单；宠物右键菜单不因本轮重设计改变现有图标。
- PetNest 品牌图标复用 `assets/icons` 中的现有资源。
- 鼠标样式预览复用现有光标主题预览图。
- 倒计时主题复用现有 `assets/countdown` 资源。
- 只有在设计图确认后仍无法用 Qt 绘制或现有素材表达的装饰图案，才新增切图；新增切图统一放在 `assets/ui/`，并记录尺寸、透明边距、用途和授权来源。

## 7. 非目标

- 不修改互动窗口的设备发现、远程伙伴、发送、动效预览和昵称流程。
- 不修改现有设置 JSON 字段含义、宠物包格式或互动协议；仅新增带默认值的 `cursor_scale` 设置字段。
- 不把导入向导和动画编辑器合并到设置中心。
- 不新增每天不同的上班时间配置。
- 不新增与本次页面重排无关的功能入口。
- 不使用真实系统背景模糊作为跨平台功能依赖。

## 8. 验收标准

- 托盘菜单不再显示“动画播放中”。
- 托盘菜单职责与顺序符合本规格；宠物右键菜单的原布局、样式、图标、项目、顺序和动态状态保持不变。
- “设置…”和“鼠标样式…”打开同一个设置中心，并能定位到相应分类。
- 互动入口继续打开原互动窗口，原有测试和行为不受影响。
- 设置中心五个分类均可编辑当前支持的设置，联动禁用和保存/取消语义正确。
- 鼠标大小能在四个吸附节点间调整，旧设置文件缺少 `cursor_scale` 时按 100% 正常运行。
- 工作倒计时能通过规律作息快速设置，也能对单个工作日设置独立下班时间；不需要逐行重复填写所有日期。
- 系统空闲页不显示会引起困惑的“时间关系会自动校验”说明。
- 导入向导和动画编辑器保持独立窗口，功能不退化，视觉令牌统一。
- 同类型窗口重复打开时不会产生重复窗口实例。
- 设计图确认后，最终实现与确认图的布局、层级、颜色和主要状态一致；无法绘制的装饰图案在实现前完成切图安置。
- 通过现有测试、编译检查、`git diff --check`，并完成至少一次实际窗口视觉检查。

## 9. 设计确认流程

1. 用户审阅本规格，确认窗口数量、设计图数量和边界。
2. 按第 3.2 节顺序制作 10 张设计图；宠物右键菜单跳过设计图制作，仅做回归确认。
3. 每张设计图单独提交用户确认；必要时只修改当前图。
4. 用户确认全部设计图后，整理实现计划。
5. 按确认图修改真实 PySide6 界面，并在实现阶段复用现有素材或补充经确认的切图。
6. 完成后按验收标准做功能和视觉验证。
