# 动画时长模式设计

## 目标

让用户能明确选择当前动作是按总时长播放还是按逐帧时长播放，并在保存后自动应用且明确反馈结果。

## 数据模型

每个本地动作覆盖保存 `mode`、`total_duration_ms` 与可选 `frame_durations_ms`：

- `total`：仅使用 `total_duration_ms`。运行时从宠物包的原始帧时长计算统一倍率，原始帧节奏不变。
- `per_frame`：仅使用 `frame_durations_ms`。运行时逐帧按该数组播放，不再叠加总时长倍率。

旧的覆盖没有 `mode` 时自动迁移：无逐帧数组的记录迁为 `total`；含逐帧数组的记录迁为 `per_frame`。

## 界面

动作表显示“当前模式”和“实际总时长”。选中动作后用互斥单选按钮选择：

- 按总时长播放：显示基准时长、可编辑目标时长与当前应用说明。
- 手动编辑每帧：显示只读总时长与逐帧表。

切换模式不会删除另一种模式的已填写值，但运行时只使用当前模式。保存后应用自动重载当前宠物，状态栏显示已应用动作、模式和时长。
