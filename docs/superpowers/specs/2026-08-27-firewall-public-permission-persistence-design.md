# 公用网络防火墙授权持久化设计

## 目标

用户明确允许 PetNest 在公用网络中进行局域网互动后，后续升级或重装必须保留该选择，不再把规则重置为仅专用网络。

## 行为

- 首次安装且没有历史选择时，仍默认仅允许专用网络。
- 安装器成功创建规则后，把是否允许公用网络记录到机器级注册表。
- 应用内“允许公用网络”修复成功后，也把允许状态记录到同一注册表位置。
- 升级或重装时，安装器读取记录并设置复选框初值；静默安装沿用记录。旧版本没有记录时，只有当前两条规则精确匹配 PetNest、UDP/TCP 18487 且包含 Public 才迁移为允许。
- 用户在交互式安装中取消勾选后，规则恢复为仅专用网络并保存取消状态。
- 完整卸载时删除该偏好，使下一次全新安装重新采用安全默认值。
- 防火墙规则仍限定为 PetNest 安装路径、UDP/TCP 18487，不扩大端口或程序范围。

## 数据边界

偏好保存在 32 位机器注册表视图的 `HKLM\Software\PetNest` 下，仅表示这台机器是否明确允许 Public 配置。安装器与提升后的应用辅助入口读写同一位置，标准用户输入管理员凭据时也不会切换偏好主体。删除已有规则失败时不得继续创建或保存偏好。

## 测试

- 安装器静态测试要求：读取已保存偏好、用其初始化复选框、配置成功后写回、卸载时删除。
- Windows 防火墙单元测试要求：提升权限辅助入口成功配置规则后记录允许状态；失败或取消时不得记录。
- 现有规则参数测试继续确保只放行 PetNest UDP/TCP 18487。
