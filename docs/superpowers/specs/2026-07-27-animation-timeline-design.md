# 动画时间线与精灵图导入设计

## 目标

让 PetNest 能从任意 8×9、192×208 格位的精灵图导入真正有内容的帧，并允许用户在不修改宠物资源包的前提下调整每个动作的播放速度。

## 导入交互

导入页在选择图片后检测每个格位的 alpha 像素，提供两个互斥模式：

- **自动跳过无内容帧**（默认）：按行从左至右导入所有 alpha 非空格位，直接保存；不修改原图。
- **手动选择所需帧**：左侧显示动作和其触发时机，右侧只显示该动作行的缩略图格位。检测到非空的格位预选，用户可点击增减选择；导出仍按原始从左到右顺序排列。

自动模式允许不连续格位，例如第 1、2、3、5、6、7 格有内容时，会输出六张连续 PNG 帧。手动模式可选透明格位，以支持刻意的停顿帧。空的 `idle` 动作不能导入，其他未选动作不会写入包。

每个导入包记录来源格位和选择结果作为元数据。该元数据不参与运行时校验，供以后重新编辑时使用。

## 播放时间线

`AnimationDefinition` 保留兼容字段 `fps`，并新增可选的 `frame_durations_ms`。存在逐帧时长时，它优先于 FPS；否则使用 `round(1000 / fps)`。动作定义另有 `speed_multiplier`，最终等待时间为基础帧时长除以该倍率。

Codex 约定的九行会提供各行已知帧时长作为导入默认值；用户选到约定范围外格位时，使用该动作的 FPS 计算默认时长。因此 PetNest 不把六帧或八帧作为上限。

## 速度编辑

托盘菜单新增“编辑动画速度…”。窗口扫描当前宠物的动作，列表展示动作名、触发时机、帧数、总时长和速度。选择动作可调速度倍率；展开“逐帧时长”后可视化编辑每帧毫秒数。

编辑结果保存在用户设置的 `animation_overrides[pet_id][action]`，而不是修改 `pet.json`。保存后立即重新载入当前窗口。无覆盖时，宠物包保持原始配置。

## 验证与错误处理

- 逐帧时长必须与帧数相同，且每项是正整数。
- 速度倍率必须大于零。
- 非法图尺寸、没有 alpha 通道或没有 idle 帧时，导入页显示原因并不写入目录。
- 旧版宠物包和设置继续工作：未提供逐帧时长或覆盖时退回原有 FPS 行为。
