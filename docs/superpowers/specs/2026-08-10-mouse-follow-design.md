# 鼠标跟随模式设计

## 目标

提供可持久化的“跟随鼠标”开关。开启后，宠物缩小、鼠标穿透、隐藏倒计时；鼠标移动时优先播放方向动作，缺失时回退到 `walk`、`drag`，静止后恢复现有状态机选择的动作。

## 设计

- 使用 Qt `QCursor.pos()` 和 20ms 计时器读取全局鼠标坐标；不使用 Windows 全局钩子，因此不增加权限或平台专属依赖。
- `MouseFollowController` 只负责移动/静止判定、目标位置和多屏边界翻转。检测到连续 150ms 无位移即判定静止。
- `PetWindow` 增加临时的“跟随动作覆盖层”。覆盖期间状态机仍接收系统空闲等事件但不改写画面；覆盖结束后播放状态机当前动作。因此 follow 不会破坏 bored、sleep、wake 等原有逻辑。
- 跟随动作优先选择 `walk_left`、`walk_right`、`walk_up`、`walk_down`（同理 `drag_*`）；没有方向帧时，向左镜像普通 `walk` / `drag`，上下移动维持最近左右朝向。临时动作即使素材配置为单次播放，也会在鼠标仍移动时循环。
- 开启时缩放为正常缩放的 45%，同时遵守宠物包最小缩放；关闭时恢复正常缩放和上次静态位置。跟随中不保存位置。
- 宠物以光标右下方 8px 偏移跟随；贴近屏幕右/下边缘时翻到左/上方，确保窗口完整在当前屏幕可用区域内。

## 交互

- 设置页：新增“跟随鼠标”勾选项与“跟随时大小”百分比（默认 45%）。
- 托盘及宠物右键菜单：新增可勾选的“跟随鼠标”。
- 跟随模式使用 `WindowTransparentForInput`，不拦截点击、键盘或拖拽；倒计时仅在普通模式显示。

## 验收

- 无 `walk` 的宠物自动使用 `drag`；两者皆无时不会失败。
- 静止后恢复状态机当前动作而非强制 idle。
- 多屏/边缘定位安全；启用时窗口鼠标穿透并隐藏倒计时。
- 设置可迁移、保存并在重启后恢复。
