# 跨平台导航栏自适应设计

## 背景

设置中心与“宠物与动作”窗口都使用 `settingsNavigation` 风格的列表导航。当前样式通过 QSS 为导航项添加上下内边距和外边距，但只有设置中心会额外根据列表的行高计算导航区域的最低高度；“宠物与动作”窗口没有对应处理。部分系统字体、Qt 平台样式或文本缩放组合下，列表项的默认尺寸提示不足以容纳实际绘制的文字和留白，导致相邻导航文字与选中背景挤压或重叠。

本次改动统一两处导航的尺寸适配，不改变页面内容、导航顺序或页面切换行为。

## 目标

- 设置中心与“宠物与动作”使用同一套导航尺寸算法。
- 跟随系统字体；字体变大时导航项同步增高，不通过缩小文字规避问题。
- 在 Windows、macOS 与 Linux 上使用 Qt 的平台度量，不依赖某个平台的显示缩放百分比。
- 导航文字不重叠、不截断，图标与文字对齐，选中背景完整覆盖对应项目。
- 普通字体与常见屏幕空间下保持现有视觉尺寸；只在内容确实放不下时增高或增宽。
- 空间不足时保持项目可读、可点击，并允许滚动访问全部项目。

## 非目标

- 不重做导航栏配色、圆角、图标或页面结构。
- 不要求不同操作系统达到逐像素一致；要求各平台满足相同的可读性和可操作性标准。
- 不调整设置中心及“宠物与动作”之外的普通列表控件。
- 不修改页面切换、离开确认、保存或导入导出等业务流程。

## 方案选择

采用共享自适应导航组件。相比在两个窗口分别补尺寸计算，它能避免逻辑漂移；相比按 DPI 百分比乘固定高度，它能同时响应显示缩放、系统文本缩放、字体差异和平台样式差异。

## 组件设计

新增共享的 `AdaptiveNavigationList`，职责仅限于导航项目的几何尺寸与重算时机。颜色、背景、圆角、字体粗细等继续由现有 QSS 控制。

组件内部使用自定义项目代理计算尺寸：

- 从当前样式选项取得文字的字体度量、图标尺寸和基础项目尺寸。
- 行高取现有设计最低高度与实际内容所需高度中的较大值。
- 实际内容高度至少包含文字或图标的较大高度，以及导航样式约定的上下留白。
- 推荐内容宽度包含最长文字、图标、图文间距和水平留白。
- 所有计算使用 Qt 的设备无关逻辑像素，不再次乘以设备像素比。

组件对外提供：

- 当前所有项目完整显示所需的“完整内容高度”。该值是宿主布局的首选高度，不会被组件无条件写成控件最低高度，以免在矮屏幕上阻止滚动。
- 当前最长项目完整显示所需的推荐内容宽度。
- 触发尺寸重算的方法，供项目批量添加完成后或宿主布局需要时使用。

## 接入方式

### 设置中心

- 将 `section_list` 改为共享自适应导航组件。
- 删除设置中心对各行 `sizeHintForRow()` 求和并手工加 QSS 上下内边距的重复逻辑。
- `_fit_to_available_geometry()` 继续处理窗口尺寸和短屏幕策略，但从共享组件取得完整内容高度；空间足够时完整展示，空间不足时允许列表缩小并滚动。
- 短屏幕仍优先隐藏“当前状态”标题与状态卡，为导航让出空间。
- 侧栏保留当前设计宽度；只有推荐内容宽度超过可用内容宽度时才增宽。增宽上限以不挤占主内容的既有最低宽度为准，达到上限后导航保留完整项目宽度并启用水平滚动。

### 宠物与动作

- 将 `navigation` 改为共享自适应导航组件。
- 保留当前导航项目、图标、选中状态和页面切换信号。
- 侧栏以当前设计宽度为下限；大字体导致最长项目放不下时，按组件推荐宽度增宽。增宽上限以不挤占主内容的既有最低宽度为准，达到上限后导航保留完整项目宽度并启用水平滚动。
- 当窗口可用高度不足以完整显示所有项目时，导航列表使用滚动条，项目行高保持不变。

两处可以配置各自已有的设计最低行高与留白，因此共享的是测量规则和响应行为，不强制两处呈现完全相同的视觉密度。

## 响应与数据流

1. 宿主创建导航组件并添加项目。
2. 项目添加完成后触发首次重算。
3. 项目代理读取当前字体、图标和样式度量，返回每行的可靠尺寸提示。
4. 组件汇总完整内容高度和最长项目宽度，并更新自身几何提示。
5. 宿主在可用几何范围内采用完整内容高度和推荐内容宽度；超过范围时缩小视口并由滚动条承接溢出内容。
6. 字体、应用样式、屏幕或设备像素比发生变化时，组件安排一次延迟重算。
7. 重算完成后刷新项目布局和选中背景。

连续到达的变化事件合并为一次下一事件循环重算，避免字体或屏幕切换期间反复触发布局。

## 空间不足与异常度量

- 空导航列表返回安全的框架和视口基础尺寸，不产生负数或无效几何值。
- Qt 样式若返回异常小的项目尺寸，组件使用可点击的最低行高作为兜底。
- 极大字体下优先保证完整文字和点击区域；若宿主高度不足，使用垂直滚动。
- 侧栏宽度只在内容需要时增加，不因显示缩放百分比直接放大。
- 几何重算不得改变当前选中项，也不得发出页面切换信号。

## 测试设计

### 共享组件测试

- 普通字体下每行不低于设计最低行高。
- 大字体下行高随实际字体高度增长。
- 带图标与不带图标的项目都能得到足够高度与宽度。
- 运行中切换字体后重新布局，项目矩形互不相交。
- 空列表返回有效尺寸。
- 连续变化事件不会造成递归布局或重复页面切换。

### 设置中心回归测试

- 普通屏幕保持现有首选尺寸与状态卡可见行为。
- 短屏幕隐藏状态卡后，全部导航可见或可滚动访问。
- 大字体下相邻项目矩形不相交，最后一项可见或可滚动到。
- 导航选中项及原有页面映射不变。

### 宠物与动作回归测试

- 五个导航项目在普通字体下保持现有视觉密度。
- 大字体下项目不重叠、文字不截断，侧栏只在需要时增宽。
- 可用高度不足时出现滚动，项目本身不被压缩。
- 选中背景与项目矩形一致，图标和文字保持对齐。
- 页面切换、离开确认和导航图标更新行为保持不变。

测试断言使用 Qt 返回的字体、样式和项目矩形，不写死 Windows 的 DPI 百分比。自动化测试覆盖平台无关的不变量；发布前在可用的平台环境进行人工抽查，重点验证常见缩放和大字体组合。

## 验收标准

- 设置中心与“宠物与动作”均使用共享导航尺寸组件。
- 默认字体下没有明显布局回归。
- 增大应用字体后，两处导航均不存在文字或选中背景重叠。
- 导航文字与图标不被裁切；空间不足时能够通过滚动访问全部项目。
- 字体、样式或屏幕环境变化后，无需重启窗口即可得到正确布局。
- 现有导航业务测试与新增自适应测试全部通过。
