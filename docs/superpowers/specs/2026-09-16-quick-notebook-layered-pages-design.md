# PetNest 轻量便签本层叠纸页设计

## 1. 目标

在不牺牲快捷记录效率的前提下，让便签本一眼具有“小本子”的辨识度，并让速记、待办、提醒三种用途容易理解。实现应严格还原视觉原型：

`.superpowers/brainstorm/notes-20260904/content/notebook-layered-tabs-v7.html`

本次只调整便签本外壳、纸页层级、页型书签、标题与空白状态、保存状态提示。待办与提醒页面内部已有 item 卡片、勾选框、进度条、时间控件和滚动行为保持原样。

## 1.1 视觉唯一基准

- 原型文件 `.superpowers/brainstorm/notes-20260904/content/notebook-layered-tabs-v7.html` 是本次外观实现的唯一视觉基准，并随规格一同纳入版本控制。
- 本文的文字描述用于解释行为和验收边界；若文字与原型的外观细节存在歧义，以原型中可见的布局、颜色、尺寸、遮挡顺序和层级关系为准。
- 实现不得只采用“相似的层叠”“接近的颜色”或默认 Qt 控件样式代替原型效果。
- 图标必须使用项目现有矢量图标体系，不得用 Unicode 或系统字符近似替代铅笔、勾选、时钟、删除、关闭、目录、翻页与保存状态图标。

原型中的关键视觉参数：

| 元素 | 参数 |
| --- | --- |
| 主纸面 | `#FFFDFA`，`1px #DECFC4` 边框，`18px` 圆角 |
| 中层纸面 | 右下偏移 `3px`，背景 `#FFFBF7`，弱阴影 |
| 底层纸面 | 右下偏移 `6px`，背景 `#FFF8F1`，最弱阴影 |
| 书签尺寸 | `80 × 45px`，右侧伸入纸内 `8px` |
| 书签垂直位置 | 速记 `34px`、待办 `91px`、提醒 `148px` |
| 书签颜色 | 紫 `#9D87D1`、绿 `#65A775`、橙 `#D99A49` |
| 后层书签 | 中层亮度约 `82%`、底层亮度约 `68%`，同时降低饱和度 |
| 顶部标题行 | 高约 `58px`，标题 `15px` 粗体，无下分割线 |
| 底部操作行 | 高约 `58px`，顶部 `1px #EEE2D8` 分隔 |
| 新建按钮 | `35 × 35px` 圆形，背景 `#D98663`，白色加号 |
| 成功浮层 | 正文右下角，背景 `#F1E8E0`，`10px` 圆角，低对比阴影 |
| 失败浮层 | 背景 `#FFF0EE`，文字 `#A34F49`，边框 `#E7BBB7` |

- 上述像素值以 100% Qt 逻辑像素为基准；125% 和 150% 由 Qt DPI 缩放，不得手工二次放大。
- 外层窗口尺寸可以沿用应用现有约束，但纸页内部各元素的比例、对齐、留白和层级必须与原型一致。

## 2. 三张纸页与层级

- 速记、待办、提醒分别拥有一张视觉纸页。
- 三张纸页在右下方向依次错开 `0px / 3px / 6px`，只露出很窄的右边和底边。
- 当前页位于最上层，使用完整纸面颜色、清晰边框与主要阴影。
- 中层纸页亮度弱化，阴影减轻。
- 最下层纸页进一步弱化，只承担层叠提示，不显示内容。
- 切换页型时，目标纸页、目标书签、边框与阴影一起提升到最上层；其余两页按固定顺序重新排列到中层和底层。
- 层级切换不改变窗口外部尺寸，也不增加大幅位移动画。

## 3. 侧边书签

- 保留原型中的紫色铅笔、绿色勾选、橙色时钟图标。
- 三个名称统一为“速记 / 待办 / 提醒”，每项两个汉字，避免“便签”同时表示整个工具和某一种页型。
- 每个书签属于对应纸页，而不是悬浮在三张纸页之上的独立导航层。
- 书签右侧向纸页内部延伸 `8px`，纸张背景和边框绘制在书签之上，形成书签根部被纸页压住的效果。
- 不论纸页位于哪一层，书签与所属纸边之间不能出现背景色断层。
- 当前书签使用完整颜色；中层书签约 `82%` 亮度和较低饱和度；底层书签约 `68%` 亮度和更低饱和度。
- 点击整块书签均可切换页型，命中区域不能只限于图标或文字。

## 4. 标题与正文

- 标题位于纸页顶部，与删除和关闭按钮处于同一行。
- 标题仍可直接编辑；未自定义标题时继续由正文第一行自动命名。
- 正文区域不再重复显示标题，也不在标题与正文之间绘制整条分割线或装饰短线。
- 标题和正文通过字号、字重和自然留白区分，保持同一张纸面的连续感。
- 标题、删除、关闭行必须保持紧凑，不能明显压缩正文高度。

## 5. 空白状态

- 空白速记页标题显示“无标题速记”。
- 正文中央显示轻量提示：“开始写点什么吧”，下方补充“第一行会自动成为标题，也可以点击上方标题自定义”。
- 用户开始输入后，空白提示立即消失，不占用文档内容，也不能被保存到正文。
- 空白待办和空白提醒可保留各自已有的添加入口，不改变 item 结构；允许补充一行低强调说明，但不能挤压 item 列表。

## 6. 保存状态提示

- 移除永久占位的“已保存到本机”文字。
- 用户内容发生变化并完成本地保存后，在当前正文区域右下角显示圆角浮层：“✓ 已保存到本机”。
- 成功浮层背景比纸面稍深，颜色低对比，不改变正文布局；显示约 `2 秒` 后淡出。
- 打开页面、切换页面或没有实际修改时不显示成功浮层。
- 连续输入使用现有防抖保存逻辑；每轮连续输入完成后只显示一次成功状态。
- 保存失败时显示常驻错误浮层：“保存失败 · 点击重试”，使用克制的红色背景和边框。
- 错误浮层不会自动消失；重试成功后切换为成功状态，再按正常时长淡出。
- 保存异常不能导致便签窗口关闭、正文丢失或当前页面被切换。

## 7. 底部操作与分类

- 保留目录、上一页、页码、下一页和新建功能。
- 新建继续使用原型中的圆形“＋”，位于翻页组最右侧；提供 tooltip 和无障碍名称“新建便签”。
- 分类入口使用动作词“归类”，已有分类显示为紧凑标签。
- 分类弹层可以覆盖在纸面上方，不永久挤占正文空间。
- 回收站、删除确认、分类数据、翻页范围和当前类别页数逻辑保持现状。

## 8. 待办和提醒 item 冻结范围

以下内容明确不在本次视觉重构范围内：

- 待办 item 的边距、高度、边框、圆角、勾选命中范围和完成态。
- 待办完成进度文字、进度条和百分比。
- 待办列表的滚动行为。
- 提醒 item 的日期块、标题、副文本、开关和展开编辑区。
- 提醒日期时间控件、重复规则和提醒列表滚动行为。

纸页层级切换只能改变这些组件所在的外层容器和可见性，不能改变其 QSS、尺寸或交互。

## 9. 分辨率与可访问性

- 100%、125%、150% 系统缩放下，三层纸边、书签贴边、顶部标题、底部操作和保存浮层均完整显示。
- 窗口受屏幕约束缩小时，优先保持正文和 item 列表可滚动，不压缩 item 固定高度。
- 书签、删除、关闭、归类、翻页和新建均提供 tooltip 与 accessible name。
- 后层书签即使变暗，也必须保持白色图标与文字可辨识。

## 10. 验收

- 视觉上能看出三张轻微错开的纸，但额外空间不超过 `6px`。
- 任一书签的根部均被所属纸边覆盖，书签与纸边之间没有断口。
- 切换任一书签后，对应纸页和书签处于最上层，另外两页依次变暗。
- 标题只在顶部出现一次，正文获得更多有效高度。
- 空白页提示清楚且开始输入即消失。
- 成功保存提示短暂浮现，失败提示持续显示并可重试。
- 待办与提醒 item 的截图对比、尺寸断言和交互测试与改造前一致。

## 11. 逐项视觉复核

实现完成后必须在 100%、125%、150% 缩放下分别截取真实 Qt 窗口，并与 v7 原型并排复核：

1. 三层纸面只露出窄右边和底边，错位不超过 `6px`。
2. 书签根部确实被纸张覆盖，接缝处没有背景色断口。
3. 当前书签颜色最亮，中层和底层能看出连续的深度衰减，文字仍清楚。
4. 标题、删除、关闭在同一基线上，顶部没有多余标题说明或分割线。
5. 正文、归类、底部目录、翻页和新建的位置与原型一致。
6. 成功浮层不推动正文、不挤压底部；失败浮层样式与成功状态有明确区别。
7. 空白页标题、正文引导的字号、居中方式和弱化程度与原型一致。
8. 待办和提醒 item 与改造前截图逐项一致，不因外层纸页改造发生尺寸或 QSS 变化。

只有以上八项全部通过，才可声称外观按照原型还原完成。
