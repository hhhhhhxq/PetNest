# 平安全屏动画设计规格

## 目标

把 `D:/downloaded/背景尽量纯色好抠图。猫从画面左侧走到画面中心后面对镜头躺下，.mp4` 转换为可导入任意 PetNest 宠物的标准动作分享 ZIP，显示名称为“平安全屏动画”。成品保留猫从屏幕左侧进入、到中心面对镜头躺下的叙事，并满足 PetNest 全屏下班提醒的播放约定。

## 交付物

- `artifacts/平安全屏动画.zip`：包含 `work_finish_walk` 与 `work_finish_lie_down` 两个全屏动作。
- 一张透明棋盘格关键帧总览图，用于快速验收抠图边缘、阴影和阶段衔接。
- PetNest 对可导入入场方向配置的向后兼容支持及相应自动测试。

## 动作包格式

两个动作均使用 `960 × 540` RGBA PNG 帧：

- `work_finish_walk`：行走、转身并面向镜头，作为全屏提醒的前 4 秒阶段；声明 `entrance_direction: "left"`。
- `work_finish_lie_down`：面对镜头躺下和翻身，播放一次，结束后由播放器停留在末帧。

全屏动作新增可选字段 `entrance_direction`，允许值为 `left`、`right`、`none`。未声明时默认 `right`，保持所有旧宠物包和旧动作包的现有行为。字段只对 `scope: "fullscreen"` 的动作有效，并在动作导入、安装、导出和再次分享时完整保留。非法值在校验或导入阶段明确报错。

安装 ZIP 时只新增或替换上述两个动作，不修改目标宠物的普通动画、绑定或其他配置。现有下班提醒解析器通过动作名识别完整的全屏动作对。

## 画面处理

源视频为 `1280 × 720`、24 fps、10 秒。处理后采用 `960 × 540`、12 fps：

1. 抠出猫主体并生成时间一致的软 alpha，清除毛边的背景色污染，避免逐帧闪烁。
2. 只保留紧贴爪子、腹部等接地点的柔和半透明阴影；去除墙面、墙脚线、地砖线、反光和大面积地面色块。
3. 在行走阶段跟踪并稳定主体锚点，不把源视频的水平位移与播放器入场位移叠加；保持猫的原始大小和垂直落地点稳定。
4. 约 `0–4 秒`输出为行走动作，约 `4 秒后`输出为躺下动作。以实际姿态连续性微调切点，但两个动作首尾必须无跳变。
5. 删除末尾重复静止帧；通过最后一帧保持实现停留，不复制静止帧。
6. 用逐帧毫秒时长校准到源视频节奏，并对 RGBA PNG 做无损优化。

ZIP 目标体积约 60 MB 以内，且必须低于导入器现有的 128 MB 解包上限。不能为了体积使用会破坏 RGBA 校验的调色板透明格式，也不使用有损边缘压缩。

## 播放器行为

全屏播放器根据 `work_finish_walk` 的 `entrance_direction` 计算帧画布横坐标：

- `left`：画布从屏幕左侧外开始，在现有 4 秒行走阶段内移动到居中位置。
- `right`：画布从屏幕右侧外开始并移动到中心，保持现有默认行为。
- `none`：画布从第一帧起直接居中，不施加横向入场位移。

三个方向使用相同的中心终点、缩放规则和现有 4 秒阶段时长。躺下阶段始终居中；播放结束后保持最后一帧，直到用户结束或关闭提醒。

## 数据流与边界

视频处理流水线只负责产生规范帧、时间线和动作 ZIP，不把素材专用逻辑写入运行时。运行时只理解通用的 `entrance_direction` 字段：

`源视频 → 主体/阴影 matte → 主体稳定与缩放 → 两阶段 RGBA 帧 → 动作 ZIP → PetNest 导入器 → 目标宠物动作目录 → 全屏播放器`

动作模型、包校验器、动作分享解析器和安装器共同承担字段的读取、校验与保留；全屏窗口只负责按已验证的值布局。这样以后其他全屏动作包也能复用入场方向能力。

## 错误处理

- 非全屏动作声明 `entrance_direction` 时校验失败，避免产生无效配置。
- 值不在 `left/right/none` 中时导入失败并显示具体字段错误。
- 两个全屏动作缺任意一个、画布不一致、帧非 RGBA、尺寸错误或逐帧时长数量不匹配时，沿用现有事务式导入失败机制，不留下半成品。
- 生成 ZIP 超过文件数、解包体积或压缩比限制时视为构建失败，不交付不可导入的文件。

## 验证

自动测试覆盖：

- 旧动作未声明字段时仍按 `right` 播放。
- `left`、`right`、`none` 在开始、中间和 4 秒终点的帧位置。
- 包加载、校验、动作解析、安装、导出和再次导入均保留合法字段。
- 非法方向、非全屏字段和格式错误被拒绝。
- 生成 ZIP 能被现有交换中心识别为两个全屏动作，帧均为 `960 × 540` RGBA，时间线长度匹配。

素材 QA 覆盖：

- 棋盘格关键帧中无墙面、地砖线或矩形底色残留。
- 毛发边缘无明显白边/灰边，保留阴影不形成地面贴片。
- 连续播放无 alpha 闪烁、主体抖动或阶段跳变。
- 在 PetNest 中实际导入 ZIP，确认从左侧进入、到中心躺下并保持末帧。
- 记录 ZIP 文件数、压缩后与解包后体积，确认符合导入限制。

## 非目标

- 不修改普通桌宠窗口的移动逻辑。
- 不增加新的提醒类型、事件绑定或设置界面。
- 不加入音频，也不保留源视频背景。
- 不改变现有全屏提醒的 4 秒行走阶段和 92% 屏幕宽度缩放规则。
