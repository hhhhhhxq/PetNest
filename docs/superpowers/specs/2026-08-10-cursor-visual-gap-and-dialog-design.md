# 光标可见间隔与独立设置页设计

## 目标

自定义光标启用时，跟随鼠标的宠物与光标的可见图案边缘保持固定 8px 间隔，而非仅距点击热点 8px。普通设置页移除光标区域，托盘“鼠标样式…”与“设置…”作为同级入口。

## 可见间隔

每个有效光标样式包包含相对热点的可见边界元数据 `follow_bounds`，按 `[left, top, right, bottom]` 表示。构建 CUR 时从实际裁切后的透明 PNG 生成该边界；运行时不扫描屏幕像素。

跟随窗口位于鼠标右下时，目标左上角使用 `cursor.x + right + 8`、`cursor.y + bottom + 8`。因屏幕边缘翻到左上时，使用 `cursor.x + left - 8 - pet_width`、`cursor.y + top - 8 - pet_height`。窗口始终被限制在当前屏幕可用区域内。

系统默认光标没有样式元数据，保留现有热点偏移 8px。无效或缺失边界的自定义样式也安全回退到 8px，且不阻止光标替换。

## 独立光标页

新增 `CursorStyleDialog`。托盘菜单顺序为“设置…”、“鼠标样式…”、“跟随鼠标”和其它现有操作；常规设置对话框不再包含光标控件。

独立页包含自定义样式开关、当前主题下拉框、预览、可见间隔说明、恢复 Windows 默认样式按钮，以及当前主题已包含角色的只读清单。关闭开关或选择恢复默认，确认后由应用层恢复全部由 PetNest 接管的角色。

一个主题包包含必填的 `arrow.cur` 和可选的 `busy.cur`、`text.cur`、`move.cur`、`resize_horizontal.cur`、`resize_vertical.cur`、`resize_diag_1.cur`、`resize_diag_2.cur`。用户只选择整套主题，不分别选择角色。主题缺少的任意资源始终使用 Windows 原样，不提示错误。首版猫爪主题只提供 `arrow.cur`，因此其它角色保持默认。

## 验证

测试覆盖：不同方向的按边界定位、无元数据回退、主题包边界与可选角色读取、独立对话框的开关与设置回写，以及常规设置页不再创建光标控件。手动验证自定义猫爪在鼠标右下与屏幕右下角翻转时均不与宠物重叠。
