# 自定义托盘图标设计

## 目标

将 PetNest 当前由 Qt 提供的默认电脑托盘图标替换为用户提供的“宠物窝”线稿图标，
使桌面与系统托盘均展示统一的 PetNest 标识。

## 图像处理

以用户提供的图片为编辑目标：保留中间的宠物窝、猫狗与爱心线稿；移除灰色渐变背景和
外部留白；生成透明背景、边缘清晰的正方形图标。输出 ICO 内含 16、20、24、32、48、64
像素层，供 Windows 在不同 DPI 与托盘尺寸下选择。

源图不会被覆盖。项目保存最终资源为 `assets/icons/petnest.ico`；如需保留处理中间 PNG，
仅置于未跟踪临时目录，不被程序引用。

## 应用加载

- `PetTrayIcon` 显式使用该 ICO 作为 `QSystemTrayIcon` 图标；
- 创建 `QApplication` 后设置同一应用图标，令窗口、任务栏及托盘保持一致；
- 资源缺失或加载失败时记录警告并安全回退至 Qt 默认图标，不妨碍宠物启动。

## 验收

启动 PetNest 后，Windows 系统托盘不再显示电脑默认图标，而显示透明背景的宠物窝线稿。
在普通与高 DPI 显示器上图标应保持清晰、无遮挡；应用启动与现有托盘菜单功能不受影响。
