# Windows 安装包与宠物库位置设计

## 目标

提供可分发的 Windows 安装包。安装向导允许选择程序目录，并以可选高级项选择宠物库目录；默认安装包只携带内置示例宠物。

## 安装向导

- 使用 Inno Setup 生成 `PetNest-Setup.exe`。
- 第一页保留标准安装目录选择，默认 `C:\Program Files\PetNest`。
- 高级项默认折叠且不勾选：`将宠物库保存到自定义位置`。
- 未勾选时，宠物库默认位于 `%LOCALAPPDATA%\PetNest\pets`。
- 勾选时显示目录选择框；安装器在首次启动前通过 `PetNest.exe --set-pets-root <目录>` 保存选择。

## 运行时资源规则

- 打包目录中的 `pets/` 只作为内置示例宠物来源，不直接修改。
- 冻结版首次启动时，如果目标宠物库没有有效宠物包，则逐包复制内置示例宠物到目标目录。
- 之后应用只从目标宠物库读取、导入和修改宠物；安装更新不会覆盖用户修改。
- 开发环境与测试中显式传入的 `pets_root` 保持原行为，不触发复制。

## 错误处理与验证

- 自定义路径无法创建或写入时，应用提示启动失败原因，不回退到安装目录写入。
- 安装器不覆盖已有用户设置；`--set-pets-root` 仅更新宠物库路径字段。
- 验证 CLI 写入、首次复制、已有库不覆盖、安装脚本资源清单与打包后的启动检查。
