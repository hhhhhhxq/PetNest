# PetNest 悬浮入口可见区域锚点设计

## 1. 目标

宠物旁的道具箱与便签本入口不再依据整个透明窗口矩形定位，而是依据当前悬浮动作所有动画帧的 Alpha 可见区域定位。入口在一次悬浮期间保持稳定，不随逐帧动画移动，同时不能覆盖悬浮动作可能出现的可见内容。

## 2. 方案选择

- 不采用“跟随当前帧”：位置会随呼吸、抬手和摇尾动作抖动。
- 不采用“只冻结出现瞬间的当前帧”：后续帧可能超出该帧轮廓并进入按钮区域。
- 不采用“合并宠物包全部动作”：跳跃、拖动等极端动作会把安全范围放大，使入口重新离宠物过远。
- 采用“当前悬浮动作全部帧的并集”：覆盖本次悬浮动画的最大可见范围，计算一次并冻结。

## 3. 可见区域计算

1. 从 `AnimationPlayer.current_frames` 读取当前动作已加载的 Pillow 帧。
2. 对每帧 Alpha 通道调用 `getbbox()`，取得非透明像素边界。
3. 合并所有有效边界为动作级原始像素包围框。
4. 原始包围框按当前宠物缩放比例转换为窗口局部坐标；左、上边界向外取整，右、下边界向外取整，避免裁掉边缘像素。
5. 若倒计时使宠物窗口变宽，加入 `_pet_left()` 水平偏移，只锚定宠物图像，不把倒计时或透明扩展画布计入可见区域。
6. 若全部帧均透明或没有帧，安全回退到当前宠物画布矩形。

动作原始包围框以动作名缓存。切换宠物包时清空缓存；缩放变化无需重新扫描 Alpha，只重新缩放缓存结果。

## 4. 冻结与生命周期

- 鼠标进入宠物且将显示悬浮入口时，先完成 `mouse.enter` 动作切换，再根据切换后的当前动作计算局部锚点。
- 将局部锚点保存为本次悬浮会话的冻结锚点。
- 动画逐帧播放或动作自动完成时，不更新冻结锚点。
- 宠物窗口整体移动时，将同一个冻结局部锚点重新映射到全局坐标，因此入口随宠物整体移动但不抖动。
- 入口隐藏、鼠标交互关闭、跟随模式开启、宠物隐藏或宠物包重新加载时，清除冻结锚点。
- 程序主动打开道具箱时，按当时动作建立同样的冻结锚点。
- 缩放比例在入口显示期间改变时，清除旧锚点并按新比例重新冻结一次。

## 5. 与现有 C 形布局的关系

- `InteractionItemToolbox.plan_launcher_arc()` 的 C 形坐标、左右镜像、屏幕约束和面板外向展开保持不变。
- 只替换传入 `show_for()` 与 `reposition()` 的 `pet_rect`：从完整窗口矩形改为冻结后的可见区域全局矩形。
- C 形布局现有 `8px` 外侧间距因此会成为相对可见宠物轮廓的真实间距。
- 只有便签本或只有道具箱一个入口时，唯一入口占用最靠近宠物的内侧槽位；两个入口同时存在时才使用 `(43, 35)` 的 C 形双槽位。
- 便签窗口和提醒卡片继续使用完整宠物窗口作为布局锚点，本次只修改悬浮小图标。

## 6. 性能

- Alpha 扫描只在某个动作首次需要锚点时执行一次。
- 后续悬浮直接读取缓存；动画 tick 不扫描图片、不重新布局。
- 复用 Pillow 已加载帧和现有 `getbbox()` 模式，不增加磁盘读取。

## 7. 测试与验收

- 透明画布左侧留白不会进入入口锚点，可见区域左边界与 Alpha 包围框一致。
- 多帧动作取所有帧边界并集，而非当前帧边界。
- 同一次悬浮期间切换动画帧，冻结锚点保持不变。
- 宠物窗口移动后，全局锚点移动相同向量。
- 倒计时扩大窗口宽度时，锚点仍贴近居中的宠物图像。
- 缩放改变后按新比例重新建立锚点。
- 无有效 Alpha 边界时回退到宠物画布，不导致入口消失或异常。
- 原有 700ms hover bridge、左右镜像、展开方向和便签点击行为全部回归通过。
- 仅有便签本入口时，右侧局部坐标为 `(0, 0)`，左侧镜像局部坐标为 `(43, 0)`，不再额外远离宠物 `43px`。
