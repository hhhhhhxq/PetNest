# 图片动作导入目标解析设计

## 目标

“用图片制作动作”必须把图片安装到用户在“选择动作”中指定的动作名。运行时 fallback 只能决定动作缺失时临时播放什么，不能改变导入、替换或草稿保存的目标。

## 行为

- 若槽位事件已有合法绑定，导入目标使用绑定中声明的动作名，即使该动作当前不存在。
- 若槽位事件没有合法绑定，导入目标使用槽位的规范动作名，并在动作包中请求创建对应事件绑定。
- 导入目标解析不遍历 fallback。例如 `system.bored` 绑定到 `bored` 且 `bored` fallback 到 `idle` 时，导入目标仍为 `bored`。
- 运行时解析和动作触发标签仍可遍历 fallback，现有播放兼容行为不变。
- 非事件槽位继续使用其规范动作名。

## 结构

在动作槽位模块中保留现有运行时解析，并增加独立的导入目标解析入口。图片导入页面和图片动作构建器改用导入目标解析；其他运行时调用不变。

## 测试

- 回归测试覆盖 `system.bored -> bored -> idle`：生成的动作包只包含 `bored`，不包含 `idle`，并保留原事件绑定。
- 槽位单元测试覆盖绑定动作缺失但存在 fallback 的情况：运行时解析可得到 fallback，导入目标仍得到绑定动作。
- 运行图片动作、槽位解析和图片导入页面相关测试，确认没有回归。
