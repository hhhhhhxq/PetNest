# 宠物与动作中心统一流程改版设计

## 文档关系

本文是对《宠物与动作导入、更新和分享中心设计》的界面与交互修订。原设计中已经实现的包识别、安全校验、事务安装、备份、动作冲突处理、预览与分享包格式继续有效。

本次改版解决三个使用体验问题：

- “导入宠物”要求用户先理解来源类型，选择成本过高。
- 精灵图导入虽然显示在统一窗口内，实际仍嵌套完整旧对话框，形成重复标题、重复按钮和不一致流程。
- 动画时长编辑仍是独立入口和独立窗口，没有成为“宠物与动作”管理的一部分。

## 目标

- 将“导入宠物”收敛为单一来源入口，由应用自动识别 PNG、ZIP 或文件夹。
- 保留原精灵图导入的全部能力，但以统一页面内容呈现，不嵌套对话框外壳。
- 将动作时长编辑纳入“宠物与动作”中心，形成导入、编辑、导出的完整闭环。
- 所有页面使用同一标题区、导航、状态区和底部操作区。
- 删除托盘中重复的旧功能入口，只留下一个清晰的统一入口。
- 不改写已经稳定的导入器、安装事务、备份和动作时间模型。

## 非目标

- 不改变宠物包、动作分享包或旧下班动画包的文件格式。
- 不改变 Codex 标准精灵图的 8×9 格式约束。
- 不增加任意散图、GIF 或视频的动作制作功能。
- 不在本次改版中重做动作触发规则编辑器。
- 不删除旧对话框所依赖的核心逻辑；如仍有内部调用需要，可由兼容外壳继续承载。

## 信息架构

“宠物与动作”窗口左侧固定为四个一级页面：

1. **导入宠物**
2. **导入动作**
3. **编辑动作**
4. **导出动作**

切换页面只替换右侧内容区，不打开新的顶层窗口。窗口统一拥有：

- 顶部页面标题、简短说明和关闭按钮。
- 左侧一级导航。
- 页面主体内容。
- 底部状态说明和当前页面主操作按钮。

页面内部不得再次出现完整对话框标题栏、关闭按钮或第二套底部按钮栏。

## 导入宠物流程

### 第一步：选择来源

页面只有一个拖放区，不再要求用户先选择“完整宠物包”或“精灵图”。支持：

- 单个 PNG 文件。
- ZIP 文件。
- 本地文件夹。

用户可以拖放，也可以分别点击“选择文件”和“选择文件夹”。文案明确说明全部内容只在本地处理，不要求用户编写 JSON。

选择后按以下规则自动识别：

- 符合标准网格条件的 PNG：进入精灵图配置流程。
- 含唯一可用 `pet.json` 的 ZIP 或文件夹：进入完整宠物包流程。
- 无法识别、存在多个包根目录或内容不安全：停留在第一步并显示具体原因。

来源类型只作为识别结果展示，不要求用户预先理解或选择。

### 第二步：设置与预览

第二步根据识别结果动态显示不同内容，但继续共用页面标题、步骤条和底部操作区。

#### PNG 精灵图

完整保留原精灵图导入能力：

- 拖放与文件选择。
- 8×9 网格检查。
- 透明格位和非空帧检测。
- 自动选择有效帧。
- 手动逐动作选择帧。
- 宠物 ID、显示名称等信息填写。
- 各动作帧缩略图与检查状态。

旧 `SpriteSheetImportDialog` 中的表单和预览逻辑需拆分成可复用的内容组件。统一中心直接挂载该内容组件，不挂载 `QDialog` 本身；如仍需保留旧对话框兼容调用，则旧对话框也组合相同内容组件。

#### 完整宠物包

显示包摘要与安装策略：

- 宠物名称、ID、作者、版本和动作数量。
- 本次操作是新增还是更新。
- 更新时的整包替换、自动备份说明。
- “保留本地新增动作”选项及其影响范围。
- 校验结果和需要处理的冲突。

### 第三步：确认导入

确认页使用统一摘要格式列出：

- 来源名称和识别类型。
- 目标宠物及新增／更新方式。
- 动作和帧数量。
- 将覆盖、保留或备份的内容。
- 校验是否通过。

点击“开始导入”前不写入宠物目录。导入成功后刷新宠物库；新增宠物默认切换到新宠物，更新当前宠物则按原有安全重载流程执行。

## 导入动作与导出动作

这两个页面继续使用现有已实现能力和数据规则，仅调整为统一视觉外壳：

- “导入动作”仍支持动作分享包、完整宠物包和旧版下班动画包。
- 来源检查、动作多选、目标宠物、冲突策略和可选触发规则保持不变。
- “导出动作”仍支持宠物选择、动作预览、多选、筛选和 ZIP 导出。
- 两页都只使用窗口级底部操作区，不自行创建嵌套按钮栏。

## 编辑动作页面

### 页面结构

“编辑动作”作为第三个一级页面，复用现有动画时长编辑能力，主体采用三栏结构：

- 左栏：当前宠物的动作列表，显示缩略图、动作 ID、帧数和总时长。
- 中栏：时长模式、数值编辑、帧时间线和逐帧时长。
- 右栏：棋盘格实时预览、播放／暂停／重播和动作摘要。

顶部右侧提供宠物选择器，默认当前宠物。底部统一显示未保存状态，并提供“恢复当前动作”和“保存并重载”。窄窗口下可优先隐藏右侧预览栏，但不能隐藏核心时长编辑功能。

### 编辑能力

保留现有两种时间模式：

- 统一设置动作总时长，由所有帧均匀分配。
- 逐帧设置每一帧停留时间。

切换模式时保留本次会话中的草稿，直到用户保存、恢复或明确放弃。切换动作后，预览按该动作实际 FPS 或逐帧时长循环播放。

`AnimationEditorDialog` 中可复用的动作列表、时间线编辑和预览应拆为页面内容组件。旧对话框若仍被测试或内部代码直接调用，可作为该组件的轻量兼容外壳，不能继续维护另一份编辑实现。

### 保存与重载

- 只有点击“保存并重载”才写入动作配置。
- 保存成功后立即重载当前宠物，并清除脏状态。
- 保存或重载失败时保留当前草稿，显示可操作错误，不关闭页面。
- “恢复当前动作”只恢复当前选中动作到磁盘值，不影响其他动作的未保存草稿。
- 切换宠物、切换一级页面或关闭窗口时，如存在未保存修改，必须提供保存、放弃或取消三个选择。

## 页面状态规则

### 导入草稿

- 在同一来源下前进或返回步骤时保留已填写内容和选择结果。
- 用户请求更换来源且当前步骤已有修改时，先确认是否丢弃当前来源草稿。
- 确认更换后只清空该导入流程的来源相关状态，不影响其他一级页面状态。
- 关闭窗口后不跨会话恢复未完成导入草稿。

### 页面切换

- 没有脏状态时可直接切换一级页面。
- 导入操作正在执行时禁用导航和关闭，直到事务完成或失败返回。
- 编辑动作存在脏状态时按保存／放弃／取消规则处理。
- 各页面的异步预览、计时器和临时来源在页面离开时停止或释放，避免后台继续播放和 ZIP 临时目录泄漏。

### 下班全屏提醒边界

保留现有安全约束：当下班全屏提醒正在使用当前宠物资源时，不允许更新或重载该宠物。界面需说明先结束提醒，再执行导入或动作保存，不在提醒播放中替换帧文件。

## 错误与反馈

- 来源识别错误必须说明用户选择了什么、缺少什么以及可行的修复方式。
- 字段错误显示在对应字段附近，底部主操作保持禁用或拒绝继续。
- 安装、保存、备份和重载错误由统一状态区展示摘要，并允许展开技术详情。
- 所有失败路径保持用户原有宠物可加载；事务失败不得留下半成品。
- 成功后使用页面内完成状态，不额外弹出只含“成功”的对话框。

## 托盘入口收敛

“宠物库”子菜单删除以下三个入口：

- “导入精灵图…”
- “导入下班动画…”
- “编辑动画时长…”

保留“宠物与动作…”，由它打开统一中心。宠物目录、刷新宠物库、重载当前宠物等基础管理项继续保留。

应用内部原有回调可在过渡阶段保留，以免无关调用立即失效，但不能再从托盘暴露重复入口。后续清理时再移除确认无引用的兼容回调。

## 组件边界

建议形成以下 UI 组件关系：

- `PetActionExchangeDialog`：统一窗口外壳、一级导航、页面切换和关闭守卫。
- `PetImportPage`：三步向导及来源类型分发。
- `SpriteSheetImportContent`：精灵图信息、网格、帧选择和预览，不拥有顶层窗口。
- `ActionImportPage`：动作来源、选择、冲突和确认。
- `AnimationEditorPage`：动作列表、编辑草稿、保存与重载编排。
- `AnimationTimingEditor`：总时长／逐帧时长编辑内容。
- `AnimationPreviewWidget`：各页面共享的动画预览。
- `ActionExportPage`：动作筛选、预览和分享包导出。

核心导入器和安装器继续保持无 Qt 依赖。UI 组件不直接复制 ZIP、改写 JSON 或执行事务替换。

## 兼容与迁移

- 原 `SpriteSheetImporter`、宠物包导入器、动作安装器和导出器直接复用。
- 原 `SpriteSheetImportDialog` 与 `AnimationEditorDialog` 可暂时保留类名和构造接口，内部改为组合新的内容组件。
- 已有测试若直接创建旧对话框，应继续通过；新增测试以统一中心页面为主。
- 已安装宠物、动作配置、备份目录和分享包无需迁移。
- 本次只移除可见菜单入口，不删除用户文件或历史备份。

## 测试策略

### 导入宠物

- 同一入口正确识别 PNG、完整宠物 ZIP 和完整宠物文件夹。
- PNG 进入精灵图设置页，完整包进入包摘要页。
- 无效来源、多包根目录和损坏 PNG 给出明确错误且不前进。
- 前进和返回保留草稿；更换来源时脏状态确认正确。
- 精灵图自动帧、手动帧选择和最终导入结果与旧流程一致。

### 编辑动作

- 宠物和动作切换正确刷新列表、时长值、时间线与预览。
- 总时长和逐帧模式互相切换时草稿不丢失。
- 恢复当前动作不影响其他动作草稿。
- 保存成功写入并重载；失败保留草稿和原文件。
- 切换页面、切换宠物和关闭窗口的保存／放弃／取消分支完整。
- 预览定时器在切换页面和关闭窗口后停止。

### 统一窗口与托盘

- 四个一级入口按“导入宠物、导入动作、编辑动作、导出动作”排列。
- 页面切换不创建额外顶层对话框，不出现重复标题或按钮栏。
- 托盘只保留“宠物与动作…”统一入口，三个旧入口不可见。
- 下班全屏提醒进行中时，当前宠物更新与动作保存被安全阻止。

### 回归

- 完整运行现有精灵图导入、动作导入、导出、动画编辑和下班提醒测试。
- 旧对话框兼容外壳的公开行为保持可用。
- 导入安全、事务回滚、备份和符号链接防护测试继续通过。

## 验收标准

- 用户在“导入宠物”中只需选择一个本地来源，不需要先理解或选择来源类型。
- PNG 精灵图的原有检查和帧选择能力完整出现在统一三步流程内，且没有嵌套对话框。
- 用户能在同一窗口切换到“编辑动作”，完成动作预览、总时长或逐帧时长编辑并保存重载。
- 四个一级页面具有一致的标题、导航、状态反馈和底部操作节奏。
- 托盘不再出现三个重复旧入口，所有相关能力都可从“宠物与动作…”进入。
- 导入或保存失败不会丢失现有宠物，也不会无提示丢失用户草稿。
