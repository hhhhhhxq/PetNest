# 鼠标样式库设计

## 目标

PetNest 可在是否开启宠物跟随均生效地替换 Windows 普通箭头光标；正常退出、关闭功能或选择系统默认时立即恢复。若异常退出，下次启动先执行恢复，避免残留自定义光标。

## 设置页

“鼠标样式”区域包含：

- `使用自定义鼠标样式` 开关；关闭即恢复系统默认。
- 当前样式下拉框、较大的静态预览图，以及“点击位置为箭头尖端”的提示。
- `恢复 Windows 默认样式` 操作。
- 可折叠的“高级光标设置”。

首版高级区只显示普通箭头的可用选择。忙碌、文本选择、拖拽/移动，以及四个调整大小方向的条目按既定位置预留，但明确显示“暂未添加样式，使用系统默认”，不能让用户误以为已生效。

## 样式与资源

样式包位于 `assets/cursors/`。每个包以元数据描述名称、缩略图、普通箭头资源和热点；后续可无破坏地增加 `busy`、`text`、`move`、`resize_horizontal`、`resize_vertical`、`resize_diagonal_1`、`resize_diagonal_2` 等资源。

首版提供系统默认和至少一个 PetNest 猫爪样式。选择样式只替换普通箭头；其他 Windows 光标保持用户现有设置。

## 生命周期与容错

替换前保存本次会话负责的角色与恢复信息。关闭样式、退出、启动失败后的清理和下一次启动的自愈都只恢复 PetNest 替换过的普通箭头，不影响其它系统角色。资源无效或替换失败时保留系统默认，并向用户显示可理解的错误。

## 验证

测试覆盖：开关/样式选择持久化，替换与恢复调用，退出和异常标记后的启动自愈，以及缺失或损坏资源的安全回退。Windows 相关调用以平台适配层隔离，非 Windows 平台保持不可用而不报错。
