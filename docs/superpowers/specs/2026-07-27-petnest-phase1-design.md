# PetNest 第一阶段设计

## 目标

PetNest 是一个基于 Python 3.12 与 PySide6 的跨平台桌面宠物播放器。核心程序只理解通用动画、事件与宠物包配置；角色素材与动作绑定均位于独立宠物包中。

## 架构

应用由五个边界清晰的部分组成：

1. `models` 定义不可变或数据化的宠物包、动画、事件和设置模型。
2. `core` 负责宠物包校验、加载、动作 fallback、确定性状态机、动画缓存与设置持久化。
3. `events` 把鼠标、应用和本地 TCP 输入归一化为事件；TCP 仅绑定 `127.0.0.1`，采用一行一个 JSON 的协议。
4. `ui` 负责透明窗口、透明像素的应用内命中判断、托盘菜单和设置窗口，不承载业务状态规则。
5. `platforms` 隔离系统空闲和启动项能力。第一阶段在不支持的平台返回明确的 unsupported 结果。

## 关键行为

状态机用宠物包 bindings 将事件映射到候选动作，再按优先级、不可中断标记、最短播放时间和 fallback 规则做确定性决策。单次动画播放完毕时由窗口提供当前上下文（鼠标是否悬停、外部持续状态）重新求值，而非一律回到 idle。

PNG 帧在加载宠物包后一次性预加载为 `QPixmap`。当前帧同时缓存 alpha 蒙版，鼠标事件只做像素读取。第一阶段实现应用内部透明区域命中判断；不尝试不稳定的系统级按像素点击穿透。

## 安全与隐私

宠物包路径必须保持在包目录内。外部事件限制大小、字段、速率和回环监听；日志只保留事件名和来源。设置使用用户配置目录和原子写入，不保存 payload 或用户内容。

## 验证策略

先以 pytest 覆盖 validator、loader、fallback、state machine、settings 和 TCP 服务；再用 pytest-qt 验证窗口基本交互。示例宠物由 Pillow 脚本生成，因此仓库不依赖来源不明的二进制美术资源。
