# PetNest 便签悬浮入口外侧顶部半圆设计

## 1. 目标

把宠物悬浮时显示的“互动道具”和“便签本”两个入口，从水平排列改为宠物外侧顶部的隐形半圆排列。界面不绘制圆、弧线、轨道或托架，只通过按钮位置形成环绕感。

视觉依据：

`/.superpowers/brainstorm/notes-20260829/content/hover-launcher-outer-top-close-v1.html`

## 2. 已确认布局

- 两个按钮保持现有 `44 × 44px`，图标保持 `25 × 25px`。
- 道具箱位于半圆靠近宠物头顶的一端。
- 便签本沿半圆向宠物外侧、下方移动。
- 两按钮中心距离约 `55px`，边缘净间距约 `11px`。
- 不显示任何轨道线，也不增加展开动画。
- 当前只有两个入口；不增加总入口、折叠按钮或二级菜单。

## 3. 右侧与左侧坐标

以宠物窗口矩形 `pet_rect` 和 `8px` 外侧间距为基础。

默认右侧：

```text
toolbox_top_left = (pet_rect.right + 1 + 8, pet_rect.top - 22)
notebook_top_left = (toolbox_top_left.x + 43, toolbox_top_left.y + 35)
```

左侧镜像：

```text
toolbox_top_left = (pet_rect.left - 8 - 44, pet_rect.top - 22)
notebook_top_left = (toolbox_top_left.x - 43, toolbox_top_left.y + 35)
```

两个按钮的相对向量恒定为 `(±43, 35)`，不能在屏幕边缘分别夹紧，否则会破坏半圆关系。

## 4. 屏幕边缘与面板展开

1. 默认选择宠物右侧。
2. 右侧按钮组或展开后的道具面板超出 `availableGeometry()` 时，整体镜像到左侧。
3. 顶部空间不足时，两个按钮整体下移，保持相对向量不变。
4. 左右均不足时，选择溢出面积较小的一侧，再整体约束进可用区域；仍不改变按钮间距。
5. 右侧布局中，道具面板从按钮组向右展开。
6. 左侧镜像布局中，道具面板从按钮组向左展开，不能覆盖宠物。
7. 宠物移动、缩放或跨屏时重新计算；按钮组和面板必须保持在宠物中心所在屏幕。

## 5. 悬浮和点击行为

- 鼠标从宠物移动到任一入口时，沿用现有 `700ms` hover bridge，不提前隐藏。
- 两个按钮的实际命中区域仍为完整 `44 × 44px`。
- 点击便签本继续切换便签窗口打开/关闭。
- 点击道具箱继续展开/收起道具面板。
- 便签本打开后，悬浮入口可以按现有逻辑隐藏；不会连带关闭便签本。

## 6. 实现边界

- 保留 `InteractionItemToolbox` 作为唯一顶层 hover 工具窗。
- 将现有水平 `launcher_strip` 改为固定尺寸的 launcher canvas，两个按钮使用绝对位置。
- 位置计算抽成纯函数，输入宠物矩形、可用屏幕和展开面板尺寸，输出侧别、窗口位置和两个按钮位置。
- 不创建第二个顶层工具窗，避免 hover 生命周期、窗口层级和跨屏状态分裂。

## 7. 测试与验收

- launcher canvas 内按钮坐标差为 `(43, 35)`，中心距离约 `55px`，边缘间距不小于 `10px`。
- 默认右侧；宠物靠右时整体镜像，按钮坐标差变为 `(-43, 35)`。
- 顶部不足时整体下移，两个按钮相对坐标保持不变。
- 道具面板在右侧向右展开，在左侧向左展开，不与宠物矩形相交。
- 100%、125%、150% DPI 下按钮尺寸、间距、屏幕约束和 hover bridge 均通过。
- 视觉复核不出现轨道线、托架、按钮重叠或宠物遮挡。
