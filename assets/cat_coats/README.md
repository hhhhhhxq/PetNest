# 键盘猫花纹素材

`tabby-mask.png` 是通过内置 imagegen 生成的灰度花纹遮罩，生成日期 2026-11-25。
黑色表示底色，白色表示条纹色；灰度表示混合强度。不是完整宠物帧。

最终提示词要点：纯黑背景、顶部少量柔和额纹，中间留空，两侧各三条自然弯曲、末端渐细的虎斑纹；不含眼睛、猫轮廓、文字、毛发纹理或键盘。
生成参数：不透明背景，竖向纹理。原始生成文件保留在本机 imagegen 输出目录。

运行时将遮罩分为额头（上方 30%）与身体（下方 70%），再映射到原有动画几何。
颜色不烘焙进素材，用户更换条纹色无需重新生成图片。Windows 与 macOS 的共用 Qt 渲染器使用同一份素材。
共用渲染器缓存有限数量的已着色纹理，避免逐帧扫描整张图片；保留的原生参考实现也缓存灰度遮罩。

其余花色沿用原有形状，以颜色图层、柔和渐变和白斑遮罩实现；眼睛始终最后独立绘制，避免保留原黑猫眼周底色。
